Craft запускает сгенерированный код в изолированных песочницах и направляет сетевой трафик песочниц через egress-прокси.
Развёртывания с самостоятельным размещением могут запускать эти песочницы в Kubernetes или Docker.

  <Card title="Kubernetes" icon="dharmachakra" href="/deployment/local/craft_kubernetes">

  </Card>

  <Card title="Docker Compose" icon="docker" href="/deployment/local/craft_docker_compose">
    Запустите контейнеры-песочницы и прокси на доверенном одиночном хосте Docker.
  </Card>
</CardGroup>

<Tip>
  Используйте Kubernetes, если Craft будут использовать больше нескольких человек,
  особенно если они могут работать одновременно. Каждому активному пользователю нужна песочница,
  поэтому Docker Compose лучше подходит для небольших развёртываний на одном хосте.
</Tip>

| | Kubernetes | Docker Compose |
| --- | --- | --- |
| Среда выполнения песочницы | Один под на активного пользователя | Один контейнер на активного пользователя |
| Рекомендуется для | Продакшена и развёртываний на нескольких узлах | Развёртываний с самостоятельным размещением на одном хосте |
| Подготовка | Helm-чарт Yahont | `onyx-cli deploy install --include-craft` |
| Доступ к хосту | API Kubernetes через ограниченный RBAC | Доступ к сокету Docker на хосте |

## Требования {#requirements}

Для обоих способов развёртывания нужны:

- Полное развёртывание Yahont с векторной базой данных и фоновыми процессами. Craft не работает на Yahont Lite.
- Поддерживаемый релиз Yahont и соответствующие версии образов приложения и песочницы.
- URL API Yahont, доступный среде выполнения песочницы, заданный как `ONYX_SERVER_URL` (Docker Compose задаёт
  работающее значение по умолчанию; для Helm он обязателен).
- Ёмкость для песочницы на каждого активного пользователя Craft.
- Поставщик Anthropic, OpenAI или OpenRouter, настроенный после развёртывания.

<Warning>
  Песочницы выполняют код, сгенерированный моделью.
  Перед включением Craft изучите [архитектуру Craft](/security/architecture/craft), особенно границы песочницы, сети,
  учётных данных и общего доступа.
</Warning>

## Когда среда выполнения готова {#after-the-runtime-is-ready}

<Steps>
  <Step title="Настройте модель">
    В **Панель администратора → Языковые модели** добавьте поставщика Anthropic,
    OpenAI или OpenRouter и сделайте хотя бы одну модель доступной пользователям Craft.
  </Step>

  <Step title="Настройте доступ рабочего пространства">
    Откройте **Панель администратора → Craft → Доступ**.
    Для ограниченного запуска оставьте значение рабочего пространства по умолчанию выключенным или включите Craft для
    всех.
  </Step>

  <Step title="Выполните полную проверку">
    От имени включённого пользователя запустите сессию Craft, отправьте запрос, создающий файл,
    и откройте или скачайте результат.
  </Step>

  <Step title="Добавьте приложения и навыки">
    Настройте внешние сервисы в **Панель администратора → Craft → Приложения** и повторно используемые рабочие процессы
    в **Craft → Навыки**.
  </Step>
</Steps>
