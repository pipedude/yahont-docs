## Режимы развёртывания {#deployment-modes}

Yahont запускается в Docker Compose в двух режимах: стандартном и «Лайт». Режим выбирается набором файлов Compose.

| | Стандартный | Лайт |
| --- | --- | --- |
| **Для кого** | Командам, которым нужны знания из своих источников | Для быстрой пробы интерфейса и команд, которым нужен только ИИ-чат |
| **Что запускается** | Все сервисы | PostgreSQL, API, веб, `nginx` и выполнение кода: 5 контейнеров |
| **Память в покое** | Около 7 ГБ | Около 1 ГБ |
| **Источники знаний и коннекторы** | Да | Нет |
| **Поиск по документам, знания агентов** | Да | Нет |
| **Чат с моделями, агенты с инструкциями и инструментами** | Да | Да |
| **Файлы и изображения в чате** | Да | Да |
| **Выполнение кода** | Да | Да |

Память измерена на нашем сервере в покое: 7,3 ГБ у стандартного режима и 0,95 ГБ у режима «Лайт».
Под нагрузкой значения будут выше.

**Стандартный режим** — полный набор возможностей Yahont. Рекомендуем его для серьёзной работы и больших команд.
В режиме «Лайт» нет этих компонентов:
- гибридный индекс (OpenSearch) для поиска по документам;
- фоновые воркеры, которые синхронизируют знания из коннекторов;
- серверы моделей эмбеддингов для индексации и поиска;
- Redis и объектное хранилище для производительности и файлов.

**Режим «Лайт»** — лёгкий интерфейс ИИ-чата. Он требует около 1 ГБ памяти и не умеет индексировать документы:
коннекторы, поиск по знаниям и знания агентов отключены. Подходит,
чтобы быстро попробовать интерфейс или если команде нужны только чат и агенты.

<Note>
  Режим «Лайт» не включает индексацию. Используйте стандартный режим,
  чтобы индексировать знания из подключённых приложений.
</Note>
