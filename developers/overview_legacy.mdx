**Почти любая функция Yahont доступна через API Yahont.**

API Yahont построены на принципах REST с форматом запросов и ответов JSON.
Все конечные точки требуют аутентификации и следуют достаточно единообразным шаблонам.

Отправляйте запросы API на адрес:

`https://cloud.yahont.ai/api` или `https://your-yahont-domain.com/api`

## Аутентификация {#authentication}

Каждый запрос аутентифицируется токеном Bearer в заголовке `Authorization`.

### Ключи API {#api-keys}

Ключи API создаются администраторами в панели администратора.
Каждый ключ существует в Yahont как отдельный пользователь, поэтому можно отслеживать активность,
держать сессии чата приватными и ограничивать ресурсы конкретным ключом.

Каждый ключ создаётся с ролью. Ролей три:

<AccordionGroup>
  <Accordion title="Ключи API администратора" icon="shield-check">
    Имеют доступ ко всем конечным точкам, включая те, что начинаются с `admin/`.

    **Сценарии использования:**
    - Полное администрирование системы
    - Операции управления пользователями
    - Управление данными и аналитика
    - Полный доступ ко всем функциям Yahont

    **⚠️ Используйте с осторожностью:** ключи администратора имеют неограниченный доступ к вашему инстансу Yahont.
  </Accordion>

  <Accordion title="Базовые ключи API" icon="key">
    Имеют доступ к конечным точкам, не относящимся к администрированию: поиск, чат, агенты и действия.

    **Сценарии использования:**
    - Создание чат-приложений
    - Реализация функций поиска
    - Создание агентов и управление ими
    - Запуск действий и рабочих процессов

    **✅ Рекомендуется:** большинству пользователей для разработки приложений стоит использовать базовые ключи API.
  </Accordion>

  <Accordion title="Ограниченные ключи API" icon="lock">
    Доступ к агентам только для чтения. Могут отправлять сообщения в конечные точки чата,
    но не могут читать историю чата.

    **Сценарии использования:**
    - Среды с очень жёсткими ограничениями
    - Особые случаи, требующие минимальных прав
    - Тестирование с ограниченной областью
  </Accordion>
</AccordionGroup>

Создавать ключи API и управлять ими могут только администраторы. Инструкции по настройке см.
в разделе [Сервисные аккаунты до версии 4.7](/admins/user_management/api_keys_legacy).

### Персональные токены доступа {#personal-access-tokens}

Персональные токены доступа (PAT) позволяют любому пользователю аутентифицировать запросы API от своего имени.
Создать токен может любой пользователь.

Чтобы создать токен, откройте **Настройки** > **Аккаунты и доступ** и нажмите **Создать новый токен**. Задайте название,
выберите срок действия (7 дней, 30 дней, 365 дней или бессрочный) и выберите его права:

| Права | Поведение |
|---|---|
| Полный доступ | Токен наследует все ваши права. |
| Ограниченный доступ | Токен ограничен выбранными вами областями. |

Ограниченный токен может использовать следующие области:

| Область | Право | Что разрешает |
|---|---|---|
| Поиск — чтение | `read:search` | Использовать конечные точки поиска и веб-поиска. |
| Чат — чтение | `read:chat` | Просматривать сессии и сообщения чата. |
| Чат — запись | `write:chat` | Создавать сессии и отправлять сообщения. Включает «Чат — чтение». |

<Warning>
  Токен показывается только один раз при создании. Сразу скопируйте его и надёжно сохраните.
</Warning>

Используйте токен как токен Bearer в заголовке `Authorization`:

```bash
curl -H "Authorization: Bearer onyx_pat_..." \
  https://cloud.yahont.ai/api/chat/get-user-chat-sessions
```

Вы можете в любой момент просмотреть, проверить и отозвать свои токены в **Настройки** > **Аккаунты и доступ**.

## Справочник API и песочница {#api-reference-and-playground}

Все конечные точки API Yahont можно найти во встроенном обозревателе OpenAPI:

`https://cloud.yahont.ai/api/docs` или `https://your-yahont-domain.com/api/docs`

<Warning>
  Обозреватель предназначен только для справки. Это не полнофункциональный клиент API.
  Игнорируйте параметр tenant_id и используйте свой ключ API как токен Bearer.
</Warning>
