---
title: "Получить агентов (администратор, постранично)"
openapi: "GET /admin/agents"
---

<Info>
  **Необходимое право:** `read:agents`, которое включают права **«Управление агентами»** и **«Управление группами»**.
  Оно есть и у администратора (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для агентов в группах, которыми он управляет.
</Info>
