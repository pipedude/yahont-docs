---
title: "Удалить агента"
openapi: "DELETE /persona/{persona_id}"
---

<Info>
  **Необходимое право:** «Создание агентов» (`add:agents`) или «Администратор» (`admin`).
  В Community Edition оно есть у каждого вошедшего пользователя. **Менеджер группы** также может вызывать этот метод,
  но только для агентов в группах, которыми он управляет.
</Info>
