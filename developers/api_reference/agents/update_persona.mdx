---
title: "Обновить агента"
openapi: "PATCH /persona/{persona_id}"
---

<Info>
  **Необходимое право:** базовый доступ (`basic`) — любой вошедший пользователь или сервисный аккаунт.
  Реальная проверка выполняется для каждого агента:
  вы должны быть его владельцем или получить к нему доступ как редактор.
</Info>
