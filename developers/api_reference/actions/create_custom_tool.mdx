---
title: "Создать пользовательский инструмент"
openapi: "POST /admin/tool/custom"
---

<Info>
  **Необходимое право:** «Управление действиями» (`manage:actions`) или «Администратор» (`admin`).
  **Менеджер группы** также может вызывать этот метод. Его область определяется агентами,
  к которым открыт доступ группам, которыми он управляет.
</Info>
