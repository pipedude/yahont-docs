---
title: "Получить попытки индексации пары «коннектор — учётные данные»"
openapi: "GET /manage/admin/cc-pair/{cc_pair_id}/index-attempts"
---

<Info>
  **Необходимое право:** `read:connectors`,
  которое включают права **«Управление коннекторами и наборами документов»** и **«Управление группами»**.
  Оно есть и у администратора (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для пар «коннектор — учётные данные» в группах, которыми он управляет.
</Info>
