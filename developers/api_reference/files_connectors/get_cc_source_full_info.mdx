---
title: "Получить полные сведения об источнике коннектора"
openapi: "GET /manage/admin/similar-credentials/{source_type}"
---

<Info>
  **Необходимое право:** «Управление коннекторами и наборами документов» (`manage:connectors`)
  или «Администратор» (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для учётных данных в группах, которыми он управляет.
</Info>
