---
title: "Список учётных данных"
openapi: "GET /manage/credential"
---

<Info>
  **Необходимое право:** базовый доступ (`basic`) — любой вошедший пользователь или сервисный аккаунт.
  Вы видите только свои собственные учётные данные.
  Право **«Управление коннекторами и наборами документов»** также позволяет видеть учётные данные без владельца и
  помеченные как публичные для администраторов.
</Info>
