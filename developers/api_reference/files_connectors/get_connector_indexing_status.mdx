---
title: "Получить статус индексации коннектора"
openapi: "POST /manage/admin/connector/indexing-status"
---

<Info>
  **Необходимое право:** «Управление коннекторами и наборами документов» (`manage:connectors`)
  или «Администратор» (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для коннекторов в группах, которыми он управляет.
</Info>
