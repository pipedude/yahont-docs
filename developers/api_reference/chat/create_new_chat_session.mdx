---
title: "Создать новую сессию чата"
openapi: "POST /chat/create-chat-session"
---

<Info>
  **Необходимое право:** «Чат — запись» (`write:chat`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Чат — запись». Оно есть и у сервисного аккаунта, не состоящего ни в одной группе.
  Анонимные пользователи могут вызывать этот метод, когда включён анонимный доступ.
</Info>
