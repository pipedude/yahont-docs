---
title: "Получить сессию чата"
openapi: "GET /chat/get-chat-session/{session_id}"
---

<Info>
  **Необходимое право:** «Чат — чтение» (`read:chat`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Чат — чтение». Анонимные пользователи могут вызывать этот метод, когда включён анонимный доступ.
</Info>
