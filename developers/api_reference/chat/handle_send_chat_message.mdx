---
title: "Отправить сообщение чата"
openapi: "POST /chat/send-chat-message"
---

<Info>
  **Необходимое право:** «Чат — запись» (`write:chat`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Чат — запись». Оно есть и у сервисного аккаунта, не состоящего ни в одной группе.
  Анонимные пользователи могут вызывать этот метод, когда включён анонимный доступ.
</Info>

<Note>
  **Запросы к нескольким моделям должны использовать потоковую передачу.** Если передать `llm_overrides` с несколькими
  элементами, модели запускаются параллельно, и требуется `stream=true`;
  сочетание с `stream=false` возвращает `400 {"error_code": "INVALID_INPUT"}`.
  Список `llm_overrides` из одного элемента игнорируется — для обычного переопределения одной модели используйте
  `llm_override`.
</Note>
