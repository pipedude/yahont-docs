---
title: "Получить права текущего пользователя"
openapi: "GET /me/permissions"
---

<Info>
  **Необходимое право:** базовый доступ (`basic`) — любой вошедший пользователь или сервисный аккаунт.
</Info>

Возвращает разрешённые права вызывающего пользователя с уже раскрытыми подразумеваемыми правами. Используйте его,
чтобы проверить, что может делать токен, до вызова конечной точки.

`is_manager` равно `true`, когда вызывающий пользователь — **менеджер группы** хотя бы одной группы,
а `managed_group_ids` перечисляет эти группы. Права управления менеджера группы действуют только внутри этих групп.
