---
title: "Список всех пользователей"
openapi: "GET /manage/users"
---

<Info>
  **Необходимое право:** `read:users`, которое включают права **«Управление группами»** и **«Управление LLM»**.
  Оно есть и у администратора (`admin`).
  **Менеджер группы** также может вызывать этот метод и получает полный список пользователей.
</Info>
