---
title: "Задать доступ администратора пользователю"
openapi: "PATCH /manage/admin/users/admin-access"
---

<Info>
  **Необходимое право:** «Администратор» (`admin`).
</Info>

Доступ администратора — это членство в группе **Admin**,
поэтому этот метод добавляет пользователя в эту группу или удаляет его из неё.

<Note>
  Чтобы выдать любое другое право, добавьте пользователя в группу, которая его даёт.
</Note>

Yahont отклоняет запрос,
если он лишил бы вас доступа к панели администратора или если аккаунт не может иметь доступ администратора:

- Вы не можете удалить себя из группы Admin. Попросите сделать это другого администратора.
- Вы не можете удалить последнего администратора. Сначала выдайте доступ администратора другому пользователю.
- Этот метод не может менять доступ администратора для сервисных аккаунтов, аккаунтов ботов,
  аккаунтов внешних прав и анонимных аккаунтов. Чтобы выдать ключу API доступ администратора,
  назначьте его сервисный аккаунт в группу Admin.
