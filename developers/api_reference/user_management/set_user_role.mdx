---
title: "Задать роль пользователя"
openapi: "PATCH /manage/set-user-role"
---

<Info>
  Этот метод применяется только к версиям Yahont до **v4.7**.
  Для Yahont v4.7 и новее используйте [Set User Admin
  Access](/developers/api_reference/user_management/set_user_admin_access), чтобы переключать членство в группе Admin.
  Чтобы выдать другие права, добавьте пользователя в группу, которая их даёт.
</Info>
