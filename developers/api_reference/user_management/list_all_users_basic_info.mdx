---
title: "Список всех пользователей (базовые сведения)"
openapi: "GET /users"
---

<Info>
  **Необходимое право:** базовый доступ (`basic`) — любой вошедший пользователь или сервисный аккаунт.
  Если в настройках безопасности для параметра **Видимость полного списка пользователей** выбрано «Видно только
  администраторам», также требуется `read:users`.
</Info>
