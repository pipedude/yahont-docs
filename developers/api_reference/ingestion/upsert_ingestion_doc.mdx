---
title: "Добавить или обновить документ загрузки"
openapi: "POST /onyx-api/ingestion"
---

<Info>
  **Необходимое право:** «Управление коннекторами и наборами документов» (`manage:connectors`)
  или «Администратор» (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для пар «коннектор — учётные данные» в группах, которыми он управляет. Пара по умолчанию публичная,
  поэтому менеджер группы не может загружать в неё данные.
</Info>
