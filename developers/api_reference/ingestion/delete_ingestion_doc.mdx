---
title: "Удалить документ из загрузки"
openapi: "DELETE /onyx-api/ingestion/{document_id}"
---

<Info>
  **Необходимое право:** «Управление коннекторами и наборами документов» (`manage:connectors`)
  или «Администратор» (`admin`). **Менеджер группы** также может вызывать этот метод,
  но только для пар «коннектор — учётные данные» в группах, которыми он управляет.
</Info>
