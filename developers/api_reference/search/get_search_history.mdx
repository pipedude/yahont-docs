---
title: "Получить историю поиска"
openapi: "GET /search/search-history"
---

<Info>
  **Необходимое право:** «Поиск — чтение» (`read:search`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Поиск — чтение».
</Info>

<Note>
  Возвращает только собственные запросы вызывающего пользователя, самые свежие первыми, и только те,
  что отправлены через [Handle Send Search Message](/developers/api_reference/search/handle_send_search_message)
  — сообщения чата и вызовы `POST /search` здесь не записываются.
  Значение `limit` вне диапазона 1–1000 или `filter_days` не больше нуля отклоняются с ошибкой `400`.
</Note>
