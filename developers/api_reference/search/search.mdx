---
title: "Поиск"
openapi: "POST /search"
---

<Info>
  **Необходимое право:** «Поиск — чтение» (`read:search`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Поиск — чтение».
</Info>

<Note>
  Используйте эту конечную точку, когда нужны результаты поиска Yahont в вашем собственном приложении.
  Она выполняет тот же конвейер извлечения, что и действие «Поиск» в чате,
  и возвращает ранжированные фрагменты документов, не тратя вызов LLM на написание ответа.
  Конечная точка интерфейса поиска Yahont — [Handle Send Search
  Message](/developers/api_reference/search/handle_send_search_message),
  которая вместо этого предоставляет расширение по ключевым словам, выбор документов с помощью LLM и потоковую передачу.
</Note>

<Warning>
  Результаты всегда фильтруются по правам вызывающего пользователя на документы,
  поэтому один и тот же запрос двух пользователей может вернуть разные документы.
  Для поиска нужна векторная база данных: развёртывания с заданным `DISABLE_VECTOR_DB` (Yahont Lite) отвечают `501`.
</Warning>
