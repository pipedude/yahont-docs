---
title: "Классификация потока поиска"
openapi: "POST /search/search-flow-classification"
---

<Info>
  **Необходимое право:** «Поиск — чтение» (`read:search`), которое включает `basic`,
  поэтому оно есть у любого вошедшего пользователя.
  Ограниченному [персональному токену доступа](/developers/overview#personal-access-tokens)
  нужна область «Поиск — чтение».
</Info>

<Note>
  Вспомогательный метод для строк запросов, которые предлагают и поиск, и чат:
  он стоит один небольшой вызов LLM и отвечает, похож ли запрос на поиск документов. Это подсказка для маршрутизации,
  а не гарантия — запросы длиннее 200 символов считаются чатом без обращения к LLM,
  а неудачная классификация возвращает `is_search_flow: false`, а не ошибку.
</Note>
