## Поток индексации {#indexing-flow}

Документы из коннекторов и загрузок пользователей обрабатываются конвейером индексации Yahont.
При конфигурации по умолчанию данные никогда не покидают развёртывание.

<img className="rounded-image" src="/assets/security/OnyxIndexingFlow.png" alt="Поток индексации Yahont"/>

<Note>
  Контекстное извлечение на основе LLM и модель информативности по умолчанию не включены.
</Note>

На схеме не показан SeaweedFS (работает локально):
он служит промежуточным хранилищем документа перед последующими шагами обработки, такими как разбиение на фрагменты.

Yahont также позволяет настроить следующие параметры:

<Info>
  Обратите внимание: изменение конфигурации по умолчанию может означать,
  что документы будут отправляться выбранным вами сторонним сервисам для обработки
</Info>

- Модель эмбеддинга через API. Команды могут выбрать её вместо выбора между запуском
  собственных GPU, использованием менее мощной модели эмбеддинга или более медленной первичной индексацией.
- Сервис подписей к изображениям.
  Подключение модели с поддержкой зрения позволяет превращать файлы со встроенными изображениями,
  а также отдельные файлы изображений в текст, чтобы их можно было представить для поиска.
- Подключение LLM для контекстного извлечения. LLM добавляет к каждому фрагменту короткую
  сводку с учётом документа, чтобы он нёс окружающий контекст, что повышает точность поиска для фрагментов,
  которые сами по себе были бы неоднозначными.

## Поток запроса {#query-flow}

<img className="rounded-image" src="/assets/security/OnyxQueryFlow.png" alt="Поток запроса Yahont"/>

Когда пользователи обращаются к Yahont, LLM определяет,
нужно ли системе получить дополнительный контекст или сразу ответить пользователю.

Если нужен дополнительный контекст, система может выполнить внутренний поиск (описан выше),
вызвать встроенное действие (например, выполнение кода или веб-поиск) или вызвать действие,
настроенное вашими администраторами.

По умолчанию система не передаёт данные во внешние системы, кроме настроенной администратором LLM.

### Телеметрия {#telemetry}

В Yahont CE анонимная телеметрия выключена (`DISABLE_TELEMETRY=true` в `.env`).
Если её включить (`DISABLE_TELEMETRY=false`), Yahont CE отправляет на сервер Yahont (`telemetry.yahont.ai`) версию,
события регистрации и действий, статусы индексации коннекторов, задержки функций,
метрики очередей и идентификатор инстанса. Тексты документов и сообщений не отправляются.

### Настраиваемые внешние сервисы {#configurable-external-services}

Администраторы системы могут настроить поддержку внешних сервисов, чтобы улучшить работу пользователей.

<Tip>
  Рекомендуется включить эти функции, чтобы пользователи получали от Yahont максимум.
</Tip>

**Веб-поиск**: отправляет поисковые запросы настроенному поставщику поиска: Srezai, Exa, Serper, Brave, Google PSE,
SearXNG, Tavily или Firecrawl. Для получения полного содержимого страницы используется краулер:
встроенный Onyx Web Crawler (запросы остаются внутри развёртывания) или Srezai, Firecrawl, Exa, Tavily.

**Генерация изображений**: отправляет промпты поставщику моделей изображений: OpenAI, Azure OpenAI, Google Vertex AI,
RouterAI или Polza.AI.

**Пользовательские действия**: вызовы API, доступные LLM, настраиваемые администраторами вашего развёртывания Yahont.
