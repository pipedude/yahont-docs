## Начало работы {#getting-started}

Когда администратор настроит расширение для Chrome для вашей организации, им можно пользоваться сразу.

**Для пользователей Yahont Cloud**: установите его прямо из Chrome Web Store

**Для пользователей с самостоятельным размещением**: инструкции по установке предоставит ваш администратор

## Использование расширения {#using-the-extension}

### **Новая вкладка** {#new-tab-experience}

- Замените стандартную новую вкладку поиском Yahont
- Быстрый поиск по знаниям вашей организации

### **Режим боковой панели** {#sidebar-mode}

- Откройте Yahont в виде боковой панели на любой веб-странице
- Задавайте вопросы о текущей работе, не покидая страницу
- Отлично подходит для исследований и вопросов, зависящих от контекста

### **Поиск по выделению** {#selection-search}

- Выделите любой текст на веб-странице
- Нажмите появившийся значок Yahont
- Мгновенно ищите или задавайте вопросы о выделенном тексте в боковой панели

### **Сочетания клавиш** {#shortcuts}

- **Mac**: `Cmd+Shift+O` — переключить новую вкладку, `Ctrl+O` — открыть боковую панель
- **Windows/Linux**: `Ctrl+Shift+O` — переключить новую вкладку, `Alt+O` — открыть боковую панель
- **Омнибокс**: введите `onyx`, затем нажмите `Tab` в адресной строке, чтобы искать напрямую
