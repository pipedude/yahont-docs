## Обзор {#overview}

Добавьте возможности ИИ Yahont прямо на свой сайт с помощью встраиваемого виджета чата.
Он построен на веб-компонентах [Lit](https://lit.dev/) для максимальной совместимости и минимального размера сборки.

Виджет легко интегрируется в любой сайт и даёт посетителям мгновенный доступ к диалогам с ИИ, не покидая вашу страницу.

## Возможности {#features}

- **Лёгкий** — сборка около 100–150 КБ в сжатом виде
- **Полностью настраиваемый** — цвета, брендинг и оформление под ваш сайт
- **Адаптивный** — всплывающее окно на компьютере, полноэкранный режим на мобильных
- **Изоляция Shadow DOM** — нет конфликтов стилей с вашим CSS
- **Потоковая передача в реальном времени** — Server-Sent Events (SSE) для быстрых ответов
- **Сохранение сессии** — диалоги сохраняются при перезагрузке страницы
- **Два режима отображения** — плавающая кнопка или встроенный блок
- **Ссылки на источники** — необязательные значки цитат со ссылками на исходные документы

## Быстрый старт {#quick-start}

Добавьте на свой сайт несколько строк:

```html
<!-- Load the widget -->
<script type="module" src="https://cdn.yahont.ai/widget/1.1/dist/onyx-widget.js"></script>

<!-- Configure and display -->
<onyx-chat-widget
  backend-url="https://cloud.yahont.ai/api"
  api-key="your_api_key_here"
  mode="launcher"
>
</onyx-chat-widget>
```

Это всё! Виджет появится в виде плавающей кнопки в правом нижнем углу страницы.

<Warning>
  **Всегда используйте для виджета API-ключ с ограниченными правами.** API-ключ виден в клиентском коде,
  поэтому у него должны быть ограниченные разрешения и лимиты запросов.
  Никогда не используйте ключи администратора или с полным доступом.
</Warning>

## Режимы отображения {#display-modes}

### Режим кнопки (по умолчанию) {#launcher-mode-default}

<video src="/assets/overview/onyx_anywhere/widget_popup.mov" alt="Всплывающее окно чата виджета Yahont" autoPlay />

В правом нижнем углу появляется плавающая кнопка. По нажатию открывается всплывающее окно чата.

- **Компьютер**: всплывающее окно 400x600 пикселей над кнопкой
- **Мобильные устройства**: полноэкранное наложение для удобства на мобильных

```html
<onyx-chat-widget mode="launcher"></onyx-chat-widget>
```

### Встроенный режим {#inline-mode}

<video src="/assets/overview/onyx_anywhere/widget_inline.mov" alt="Встроенный режим виджета Yahont" autoPlay />

Виджет встраивается прямо в макет страницы. Отлично подходит для страниц поддержки и баз знаний.

```html
<div style="width: 400px; height: 600px;">
  <onyx-chat-widget mode="inline"></onyx-chat-widget>
</div>
```

<Tip>
  В встроенном режиме виджет занимает все размеры своего контейнера. Размер виджета задаётся размером контейнера.
</Tip>

## Параметры настройки {#configuration-options}

### Обязательные атрибуты {#required-attributes}

| Атрибут       | Тип    | Описание                             |
| ------------- | ------ | ------------------------------------ |
| `backend-url` | string | URL API вашего бэкенда Yahont         |
| `api-key`     | string | API-ключ для аутентификации          |

### Необязательные атрибуты {#optional-attributes}

| Атрибут            | Тип    | По умолчанию  | Описание                                 |
| ------------------ | ------ | ------------- | ---------------------------------------- |
| `agent-id`         | number | `undefined`   | Конкретный агент (персонаж) для использования |
| `agent-name`       | string | `"Assistant"` | Отображаемое имя в заголовке             |
| `logo`             | string | Логотип Yahont | URL пользовательского логотипа           |
| `primary-color`    | string | `#1c1c1c`     | Основной цвет бренда (кнопки, акценты)   |
| `background-color` | string | `#e9e9e9`     | Цвет фона виджета                        |
| `text-color`       | string | `#000000bf`   | Цвет текста (чёрный с непрозрачностью 75%) |
| `mode`             | string | `"launcher"`  | Режим отображения: `"launcher"` или `"inline"` |
| `include-citations`| boolean| `false`       | Показывать значки цитат со ссылками на исходные документы |

<Warning>
  **Цитаты и приватные документы:** если включён `include-citations`, виджет будет цитировать любые документы,
  доступные настроенному агенту или API-ключу. Если у агента есть доступ к приватным или внутренним документам,
  ссылки в цитатах могут вести на ресурсы, которые конечные пользователи не могут просмотреть.
  Правильно ограничьте доступ агента к документам или отключите цитаты для общедоступных развёртываний с
  конфиденциальными источниками.
</Warning>

### Примеры настройки {#configuration-examples}

**Базовая настройка:**

```html
<onyx-chat-widget
  backend-url="https://cloud.yahont.ai/api"
  api-key="on_abc123">
</onyx-chat-widget>
```

**Полная настройка:**

```html
<onyx-chat-widget
  backend-url="https://cloud.yahont.ai/api"
  api-key="on_abc123"
  agent-id="42"
  agent-name="Support Bot"
  logo="https://yoursite.com/logo.png"
  primary-color="#FF6B35"
  background-color="#FFFFFF"
  text-color="#1A1A1A"
  mode="launcher"
  include-citations="true"
>
</onyx-chat-widget>
```

## Оформление {#customization}

### Стили {#styling}

Виджет использует пользовательские свойства CSS для темизации. Все стили изолированы в Shadow DOM,
чтобы не конфликтовать с CSS вашего сайта.

**Цвета по умолчанию:**

| Переменная CSS          | По умолчанию | Описание                 |
| ----------------------- | ----------- | ------------------------ |
| `--onyx-primary`        | `#1c1c1c`   | Кнопки, акценты          |
| `--onyx-primary-hover`  | `#000000`   | Состояние при наведении  |
| `--onyx-background`     | `#e9e9e9`   | Фон виджета              |
| `--onyx-text`           | `#000000bf` | Текст (непрозрачность 75%) |
| `--onyx-text-light`     | `#ffffff`   | Белый текст на тёмном    |
| `--onyx-border`         | `#00000033` | Границы (непрозрачность 20%) |

**Переопределение через атрибуты:**

```html
<onyx-chat-widget
  primary-color="#FF6B35"
  background-color="#FFFFFF"
  text-color="#1A1A1A"
>
</onyx-chat-widget>
```

## Архитектура {#architecture}

Виджет общается напрямую с вашим бэкендом Yahont, используя Server-Sent Events (SSE)
для потоковой передачи ответов в реальном времени:

**Виджет загружается** — лёгкая сборка JavaScript инициализирует веб-компонент

**Создаётся сессия** — виджет создаёт сессию чата через API Yahont

**Пользователь отправляет сообщение** — запрос отправляется на ваш бэкенд Yahont

**Потоковый ответ** — ответ ИИ передаётся обратно в реальном времени через SSE

**Отрисовывается Markdown** — ответы форматируются с полной поддержкой Markdown
