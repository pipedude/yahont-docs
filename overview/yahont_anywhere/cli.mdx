Yahont CLI — это терминальный интерфейс для общения с вашими агентами Yahont и запросов к базе знаний.
Он написан на Go с использованием [Bubble Tea](https://github.com/charmbracelet/bubbletea)
и предлагает как интерактивный TUI, так и неинтерактивные команды для скриптов и автоматизации.

## Установка {#installation}

### PyPI (рекомендуется) {#pypi-recommended}

```shell
uv tool install onyx-cli
```

Или через pip:

```shell
pip install onyx-cli
```

### Сборка из исходного кода {#build-from-source}

Требуется [Go 1.26+](https://go.dev/dl/).

```shell
git clone --depth 1 https://github.com/onyx-dot-app/onyx.git
cd onyx/cli
go build -o onyx-cli .
sudo mv onyx-cli /usr/local/bin/
```

## Настройка {#setup}

Запустите интерактивный чат TUI — при первом запуске он проведёт вас через настройку:

```shell
onyx-cli chat
```

Он запросит URL вашего сервера Yahont и персональный токен доступа (PAT),
проверит подключение и сохранит конфигурацию в `~/.config/onyx-cli/config.json` (или в
`$XDG_CONFIG_HOME/onyx-cli/config.json`, если эта переменная задана). Чтобы позже перенастроить,
используйте слэш-команду `/configure` внутри TUI.

### Создание токена доступа {#generating-an-access-token}

Откройте **Настройки > Аккаунты и доступ > Новый токен доступа** (`/app/settings/accounts-access`),
чтобы создать токен доступа для CLI.

### Переменные окружения {#environment-variables}

Переменные окружения переопределяют значения из файла конфигурации. Это удобно для CI/CD и скриптов.

| Переменная | Обязательна | Описание |
|----------|----------|-------------|
| `ONYX_SERVER_URL` | Нет | Базовый URL сервера (по умолчанию: `https://cloud.yahont.ai`) |
| `ONYX_PAT` | Нет | Персональный токен доступа для аутентификации (обязателен, если нет файла конфигурации) |
| `ONYX_PERSONA_ID` | Нет | ID агента (персонажа) по умолчанию |

### Проверка конфигурации {#validate-configuration}

Проверьте, что конфигурация верна и сервер доступен:

```shell
onyx-cli validate-config
```

## Команды {#commands}

| Команда | Описание |
|---------|-------------|
| `onyx-cli chat` | Запустить интерактивный чат TUI (включает первоначальную настройку) |
| `onyx-cli ask` | Задать разовый вопрос (неинтерактивно) |
| `onyx-cli search` | Искать по знаниям компании и получить ранжированные документы |
| `onyx-cli agents` | Показать список доступных агентов |
| `onyx-cli validate-config` | Проверить конфигурацию и протестировать подключение |
| `onyx-cli deploy` | Установить и обслуживать самостоятельно размещаемое развёртывание Yahont |

### Интерактивный чат {#interactive-chat}

```shell
onyx-cli chat
```

Открывает полноэкранный терминальный интерфейс для диалога с вашими агентами Yahont.

### Разовые вопросы {#one-shot-questions}

Задайте вопрос и получите ответ, не заходя в TUI:

```shell
onyx-cli ask "What is our company's PTO policy?"
```

Параметр `--agent-id` позволяет выбрать конкретного агента:

```shell
onyx-cli ask --agent-id 5 "Summarize our Q4 roadmap"
```

Параметр `--json` включает структурированный вывод NDJSON (удобно для скриптов):

```shell
onyx-cli ask --json "List all active API integrations"
```

| Флаг | Описание |
|------|-------------|
| `--agent-id <int>` | ID используемого агента (переопределяет значение по умолчанию) |
| `--json` | Выводить события NDJSON вместо обычного текста |

### Список агентов {#list-agents}

```shell
onyx-cli agents
onyx-cli agents --json
```

Выводит таблицу с ID, названиями и описаниями доступных агентов.

### Самостоятельное развёртывание {#self-hosted-deployment}

Группа команд `deploy` устанавливает и обслуживает самостоятельно размещаемое развёртывание Yahont на Docker Compose —
это установщик с подсказками, а также команды `upgrade`, `status`, `logs`, `stop` и `uninstall`:

```shell
onyx-cli deploy install
```

## Слэш-команды (интерактивный TUI) {#slash-commands-interactive-tui}

В интерактивном чате доступны следующие слэш-команды:

| Команда | Описание |
|---------|-------------|
| `/help` | Показать справку |
| `/new` | Начать новую сессию чата |
| `/agent` | Показать агентов и переключиться между ними |
| `/attach <path>` | Прикрепить файл к следующему сообщению |
| `/sessions` | Показать недавние сессии чата |
| `/clear` | Очистить отображение чата |
| `/configure` | Повторно запустить настройку подключения |
| `/connectors` | Открыть коннекторы в браузере |
| `/settings` | Открыть настройки в браузере |
| `/quit` | Выйти из Yahont CLI |

## Использование в качестве навыка ИИ-помощника для программирования {#using-as-an-ai-coding-assistant-skill}

Yahont CLI можно использовать как инструмент в ИИ-помощниках для программирования (например, Claude Code и Cursor),
чтобы обращаться к вашей базе знаний прямо из среды разработки.
Готовое описание навыка есть в репозитории `onyx-dot-app/onyx`:
[`.cursor/skills/onyx-cli/SKILL.md`](https://github.com/onyx-dot-app/onyx/blob/main/cli/internal/embedded/SKILL.md).

После настройки ИИ-помощник может вызывать `onyx-cli ask`, чтобы получать сведения о вашей компании — политики,
внутренние документы, подключённые источники данных — не выходя из редактора.

### Когда вызывается навык {#when-the-skill-is-invoked}

Навык срабатывает, когда вы спрашиваете ИИ-помощника о:

- Сведениях о компании (политики, процессы, документация)
- Внутренних базах знаний или подключённых источниках данных
- Чём угодно, что упоминает Yahont, «поиск в Yahont» или запросы к документам компании

Он **не** используется для общих вопросов по программированию и вопросов о коде в текущем репозитории.

### Настройка для агентов {#configuration-for-agents}

Проще всего один раз вручную запустить `onyx-cli chat` и пройти первоначальную настройку — после этого ИИ-помощники
смогут вызывать `onyx-cli ask` напрямую без дополнительных действий.

```shell
onyx-cli chat
```

Либо можно настроить через переменные окружения,
которые переопределяют файл конфигурации и удобны для CI/CD и изолированных сред:

```shell
export ONYX_SERVER_URL="https://your-yahont-server.com"
export ONYX_PAT="your-pat"
```

### Вывод JSON для структурного разбора {#json-output-for-structured-parsing}

Используйте `--json`, чтобы получать события в формате NDJSON — агентам их проще разбирать программно:

```shell
onyx-cli ask --json "List all active API integrations"
```

| Тип события | Описание |
|------------|-------------|
| `message_delta` | Токен содержимого — для полного ответа объедините все поля `content` |
| `stop` | Поток завершён |
| `error` | Ошибка с полем сообщения `error` |
| `search_tool_start` | Yahont начал поиск документов |
| `citation_info` | Ссылка на источник с полями `citation_number` и `document_id` |

## Сочетания клавиш {#keyboard-shortcuts}

| Клавиша | Действие |
|-----|--------|
| `Enter` | Отправить сообщение |
| `Escape` | Отменить текущую генерацию |
| `Ctrl+O` | Показать или скрыть ссылки на источники |
| `Ctrl+D` | Выйти (нажмите дважды) |
| `Scroll` / `Shift+Up/Down` | Прокрутка истории чата |
| `Page Up` / `Page Down` | Прокрутка на пол-экрана |
