Craft — это ИИ-коллега, который проведёт цель от запроса до готового результата. Он планирует работу, собирает контекст,
пишет и запускает код, создаёт файлы и дорабатывает результат в защищённой песочнице.

| Попросите Craft                       | Пример результата                                                                   |
| ------------------------------------- | ----------------------------------------------------------------------------------- |
| **Исследовать и обобщить**            | Сводка по клиенту на основе знаний компании и актуальных данных приложений.         |
| **Подготовить готовый материал**      | Презентация, отчёт, таблица, документ, изображение или файл для экспорта.           |
| **Создать интерактивный инструмент**  | Дашборд, обозреватель данных, калькулятор или другое веб-приложение, которым можно поделиться. |
| **Выполнить работу в другом сервисе** | Черновик письма, обновлённая задача в проекте, сохранённый файл или pull request.   |

<img className="rounded-image" src="/assets/overview/core_features/craft_overview.png" alt="Сессия Craft с созданным дашбордом, открытым на панели результатов"/>

<Tip>
  Хотите включить Craft в своём развёртывании Yahont? Читайте руководства по [развёртыванию](/deployment/local/craft)
  и [администрированию](/admins/managing_features/craft).
</Tip>

Craft запускает сгенерированный код в песочнице, изолированной от вашего компьютера и инфраструктуры Yahont.
Организация сама решает, к какой информации Craft имеет доступ и какие действия может выполнять.
Полную модель доверия и сетевого взаимодействия смотрите в разделе [Архитектура Craft](/security/architecture/craft).

## Запуск сессии Craft {#start-a-craft-session}

Каждая новая сессия получает отдельное рабочее пространство, где Craft может создавать файлы,
запускать код и показывать предпросмотр веб-приложений. Для выполнения запроса он может использовать знания компании,
файлы из пользовательской библиотеки, доступные навыки и подключённые приложения.

<img className="rounded-image" src="/assets/overview/core_features/craft_workspace_clean.png" alt="Сессия Craft: цикл работы агента слева и живой предпросмотр дашборда справа"/>

<Note>
  Если Craft не отображается на боковой панели Yahont, он не включён для вашего рабочего пространства.
  Попросите администратора включить Craft и убедиться, что доступен поддерживаемый поставщик моделей.
</Note>

### Как написать хороший первый запрос {#write-a-strong-first-prompt}

Выберите модель, опишите нужный результат и укажите контекст, который должен использовать Craft.

<img className="rounded-image" src="/assets/overview/core_features/craft_start.png" alt="Главный экран Craft с полем запроса, выбором модели и ссылками для подключения источников данных"/>

После отправки первого сообщения сменить модель нельзя, поэтому выберите её до отправки.

| Что указать                | Что сообщить Craft                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| **Конечный продукт**       | Нужно ли веб-приложение, отчёт, презентация, сводка, обозреватель данных или файл для экспорта. |
| **Аудитория и цель**       | Кто будет использовать результат и что ему нужно.                                           |
| **Исходные материалы**     | Источники компании, подключённые приложения, примеры или файлы, на которые должен опираться Craft. |
| **Важные требования**      | Разделы, тон, графики, фильтры, имена файлов или формат вывода, которые имеют значение.     |

<Tip>
  Craft рассчитан на то, чтобы двигаться вперёд, и часто делает разумные допущения.
  Укажите важные ограничения в первом запросе, а затем уточняйте результат по ходу работы.
</Tip>

### Пример: презентация для общего собрания {#example-build-an-all-hands-deck}

> Подготовь презентацию для общего собрания за 2 квартал. Возьми достижения из Slack, упомяни
> потенциальных и текущих клиентов из HubSpot, приведи цифры из нашего документа по синхронизации продаж
> и используй наш шаблон для общих собраний.

Craft соберёт нужный контекст, будет следовать навыку создания презентаций и шаблону вашей компании,
поручит слайды субагентам и соберёт итоговую презентацию.

<img className="rounded-image" src="/assets/overview/core_features/craft_agent_loop.png" alt="Сессия Craft создаёт презентацию для инвесторов и поручает отдельные слайды параллельным субагентам"/>

## Следите за работой {#follow-the-work}

Панель чата в реальном времени показывает ход работы Craft:

| Активность      | Что показывает                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Задачи**      | План, по которому работает Craft, с отметками о выполнении.                                                        |
| **Размышление** | Как Craft подходит к следующему шагу.                                                                              |
| **Работа**      | Вызовы инструментов, например поиск по знаниям компании или чтение файла из приложения.                            |
| **Выполнение**  | Команды в песочнице, например написание кода, установка пакетов или запуск сервера разработки.                     |
| **Субагенты**   | Специализированные агенты, параллельно работающие над частями большой задачи, например над отдельными слайдами или разделами отчёта. |

Откройте субагента из меню в заголовке, чтобы прочитать его расшифровку.
Ваши сообщения по-прежнему уходят в основную сессию. Статус в заголовке показывает, что песочница инициализируется,
работает или восстанавливается.

Направлять выполнение можно в любой момент:

| Действие                    | Что делает                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Одобрить действие**       | Позволяет проверить действие приложения, если политика организации требует одобрения.                         |
| **Поставить уточнение в очередь** | Даёт Craft ещё одну инструкцию, которую он выполнит после текущего шага.                                |
| **Прервать**                | Останавливает текущий запуск при нажатии **Esc**. Сообщения и файлы сохраняются, так что можно поменять направление. |

## Дайте Craft контекст {#give-craft-context}

Craft может начать работу только с запроса,
но конкретные ссылки помогают ему найти нужную информацию и получить именно тот результат,
который вы себе представляете. Используйте **+** в поле ввода, чтобы прикрепить файлы или выбрать навык или приложение.
Файлы также можно перетащить в чат.

| Источник                | Подходит для                                                                 |
| ----------------------- | ---------------------------------------------------------------------------- |
| **Знания Yahont**        | Материалы компании, к которым у вас уже есть доступ.                         |
| **Публичный интернет**  | Актуальная публичная информация и сайты, по которым нужно перемещаться Craft. |
| **Вложения сессии**     | Файлы, нужные только в этой сессии, например CSV, PDF, заметки или изображение. |
| **Пользовательская библиотека** | Файлы для повторного использования во всех сессиях, например шаблоны. |
| **Навыки**              | Повторно используемые инструкции, примеры и файлы, обучающие Craft методу.   |
| **Приложения**          | Актуальная информация и одобренные действия во внешних подключённых сервисах. |

Вложения сессии остаются в одной сессии.
Файлы пользовательской библиотеки остаются доступными для повторного использования во всех сессиях.

Если доступен навык «Браузер», Craft может открывать публичные сайты, переходить по ссылкам,
взаимодействовать со страницами и делать скриншоты. Он использует собственный браузер в песочнице,
а не сессию вашего браузера и сохранённые входы.

<Accordion title="Ограничения на файлы и хранилище">
  Это ограничения по умолчанию. Администратор может изменить их для развёртываний с самостоятельным размещением.

  **Вложения сессии**

  | Ограничение                          | По умолчанию |
  | ------------------------------------ | ------------ |
  | Максимальный размер файла            | 50 МБ        |
  | Максимальное число файлов в сессии   | 20           |
  | Максимальный общий размер в сессии   | 200 МБ       |

  **Пользовательская библиотека**

  | Ограничение                           | По умолчанию |
  | ------------------------------------- | ------------ |
  | Максимальный размер файла             | 500 МБ       |
  | Максимальное число файлов за загрузку | 100          |
  | Максимальный общий объём хранилища    | 10 ГБ        |

  Пользовательская библиотека принимает обычные файлы и ZIP-архивы. ZIP-файлы распаковываются,
  чтобы Craft мог работать с файлами внутри.
</Accordion>

<Warning>
  Не загружайте секреты, приватные токены и рабочие учётные данные в виде файлов.
  Подключите [приложение](/overview/core_features/craft_apps),
  если Craft нужен авторизованный доступ к внешнему сервису.
  Исходные учётные данные приложений никогда не попадают в рабочее пространство песочницы.
</Warning>

## Проверка результата {#review-the-result}

Откройте **Результат** в правом верхнем углу сессии, чтобы изучить созданное Craft.

| Вкладка         | Что показывает                                                                        |
| --------------- | ------------------------------------------------------------------------------------- |
| **Предпросмотр** | Живое веб-приложение, которое обновляется по мере изменения файлов Craft.            |
| **Файлы**       | Всё рабочее пространство сессии, включая исходный код, данные и промежуточные материалы. |
| **Артефакты**   | Готовые результаты для скачивания или передачи, обычно записываются в `outputs/`.     |

<img className="rounded-image" src="/assets/overview/core_features/craft_files.png" alt="Панель результатов со вкладками «Предпросмотр», «Файлы» и «Артефакты» и файлами рабочего пространства сессии"/>

Можно скачивать отдельные файлы, скачивать папку или веб-приложение в виде ZIP-файла,
экспортировать Markdown в файл .docx и просматривать изображения, PDF, презентации и текстовые файлы.

### Как поделиться веб-приложением {#share-a-web-app}

Веб-приложения работают в песочнице, и доступ к ним предоставляется через Yahont, а не напрямую.
Нажмите **Поделиться** на вкладке «Предпросмотр», затем выберите, кто может открыть приложение:

| Область          | Доступ                                                  |
| ---------------- | ------------------------------------------------------- |
| **Приватное**    | Только вы можете открыть приложение, которым поделились. |
| **Организация**  | Любой, кто вошёл в ваш Yahont, может его открыть.        |

Общий доступ распространяется только на сгенерированное веб-приложение. Диалог и другие файлы сессии не передаются.

### Как доработать результат {#refine-the-result}

Продолжайте в той же сессии и просите об изменениях простым языком:

- **Изменить макет:** «Добавь фильтр за последние 30 дней и перенеси сводные карточки наверх».
- **Изменить текст:** «Перепиши краткое резюме для нетехнической аудитории и сократи до трёх предложений».
- **Подготовить итоговый файл:** «Добавь в отчёт краткое резюме из одного абзаца и сохрани итоговую версию в `outputs/`».
