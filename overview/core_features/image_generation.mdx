## Обзор {#overview}

Функция генерации изображений позволяет пользователям создавать PNG-изображения по своим запросам.
Их можно показать в чате и легко скачать.

<img className="rounded-image" src="/assets/overview/core_features/image_generation.png" alt="Генерация изображений"/>

## Настройка {#configuration}

Администратор подключает модель генерации изображений у одного из поставщиков. Список в панели администратора такой:

**RouterAI и Polza.AI** (группа «Работает в РФ без VPN»). Нужен ваш ключ поставщика. Доступны две модели:

- **GPT Image 2.5 Sunburst**: премиальная модель генерации изображений OpenAI для самых точных правок.
- **GPT Image 2.5 Flare**: новейшая модель генерации изображений OpenAI: высокое качество и быстрая генерация.

**OpenAI**:

- **GPT Image 2.5 Flare**: новейшая модель генерации изображений OpenAI: высокое качество и быстрая генерация.
- **GPT Image 2.5 Sunburst**: премиальная модель генерации изображений OpenAI для самых точных правок.
- **GPT Image 2**: модель генерации изображений OpenAI предыдущего поколения с высокой точностью промпта.
- **GPT Image 1.5**: предыдущая флагманская модель генерации изображений OpenAI.
- **GPT Image 1**: способная модель генерации изображений от OpenAI с сильным следованием промпту.

**Azure OpenAI**: те же пять моделей (GPT Image 2.5 Flare, GPT Image 2.5 Sunburst, GPT Image 2,
GPT Image 1.5 и GPT Image 1) на Microsoft Azure. Модель определяется по развёртыванию в URL.

**Google Cloud Vertex AI**:

- **Gemini 2.5 Flash Image** (Nano Banana): создана для скорости и эффективности.
- **Gemini 3 Pro Image** (Nano Banana Pro): создана для профессионального производства ресурсов.

<Note>
  В Yahont Cloud доступны только RouterAI и Polza.AI: OpenAI,
  Azure OpenAI и Google Cloud Vertex AI в облаке не предлагаются, потому что облако размещено в России.
</Note>

## Использование {#usage}

Настройте модели генерации изображений в панели администратора: **Генерация изображений**.

После настройки действие «Генерация изображений» можно вызвать у любого агента или ИИ-модели в Yahont.

<Tip>
  В запросе прямо указывайте действия, которые должен вызвать агент.
</Tip>
