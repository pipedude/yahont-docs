Действие «Выполнение кода» даёт LLM в Yahont возможность писать и выполнять код на Python, открывая такие возможности,
как сложные вычисления, анализ данных в загруженных файлах и создание или изменение документов.

<Tip>
  Действие «Выполнение кода» встроено и доступно во всех развёртываниях без какой-либо настройки.
</Tip>

<img className="rounded-image" src="/assets/overview/core_features/code_interpreter.png" alt="Выполнение кода"/>

<Info>
  LLM сама определяет, когда использовать выполнение кода, исходя из запроса пользователя, — явный вызов не нужен.
  Действие также можно подключить к пользовательским [агентам](/admins/agents/overview),
  чтобы LLM могла использовать его по необходимости.
</Info>

## Возможности {#features}

Действие «Выполнение кода» работает в защищённой изолированной среде Python,
из которой удалена вся опасная функциональность (например, доступ к сети и файловой системе за пределами песочницы).

- **Библиотеки**: установлены numpy, pandas, scipy, matplotlib и другие библиотеки.
- **Входные файлы**: вместе с кодом можно передать файлы любых типов, чтобы обработать их.
- **Выходные файлы**: файлы можно создавать и возвращать пользователю.
- **Перехват STDIN/STDOUT**: весь вывод программ перехватывается и показывается пользователю.
- **Отрисовка графиков**: [интерфейс чата](/overview/core_features/chat) Yahont
  показывает возвращённые графики и другие визуализации прямо в диалоге.
