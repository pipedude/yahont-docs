<Note>
  Агент по коду — **бета**-функция.
  По умолчанию она отключена и пока поддерживает только **публичные** репозитории GitHub. Как её включить, см.
  в разделе [Настройка](#configuration) ниже.
</Note>

## Обзор {#overview}

Агент по коду даёт Yahont возможность исследовать репозиторий GitHub и отвечать на вопросы о его кодовой базе.
Получив репозиторий и вопрос,
он клонирует репозиторий в изолированную песочницу и изучает код с помощью команд оболочки,
после чего возвращает письменный ответ.

Это открывает такие сценарии:

- **Понимание кодовой базы**: спросите, как реализована функция или где находится фрагмент логики.
- **Адаптация новичков**: получите общее описание структуры проекта и ключевых модулей.
- **Исследование кода**: проследите, как данные проходят через приложение или как взаимодействуют два компонента.
- **Ответы на вопросы «где / как / почему»**: найдите нужные файлы и получите краткое описание того, что делает код.

<Info>
  LLM сама определяет, когда использовать агента по коду, исходя из запроса пользователя. Как и другие действия,
  его можно подключить к пользовательским [агентам](/admins/agents/overview),
  чтобы LLM могла использовать его по необходимости. Явно указывайте в запросе,
  какой репозиторий нужно проанализировать.
</Info>

## Как это работает {#how-it-works}

Когда вызывается агент по коду, он:

<Steps>
  <Step title="Клонирует репозиторий">
    Целевой репозиторий GitHub клонируется в изолированную среду-песочницу.
  </Step>

  <Step title="Исследует код">
    Итеративный цикл под управлением LLM выполняет команды оболочки, чтобы изучить кодовую базу.
  </Step>

  <Step title="Возвращает ответ">
    На основе найденного формируется итоговый письменный ответ.
  </Step>
</Steps>

Агент по коду работает в той же изолированной среде,
что и [интерпретатор кода](/overview/core_features/code_interpreter),
поэтому ему нужен подключённый сервер выполнения bash и кода.

## Настройка {#configuration}

Поскольку агент по коду — бета-действие, по умолчанию он **отключён**.
Администратор может включить его на вкладке **Действия** панели администратора,
а затем подключить к нужным [агентам](/admins/agents/overview).

Подробнее о включении агента по коду и управлении им читайте в [руководстве по настройке для
администраторов](/admins/actions/coding_agent).

## Ограничения {#limitations}

- **Только публичные репозитории**: приватные репозитории пока не поддерживаются, клонирование завершится ошибкой.
  Поддержка приватных репозиториев запланирована.
- **Бета**: поведение и настройки могут меняться по мере развития функции.
