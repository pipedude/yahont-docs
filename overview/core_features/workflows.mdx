## Что появится {#whats-coming}

Функция рабочих процессов Yahont позволит:

- **Асинхронные действия**: настроить запуск агентов по событиям или по расписанию.
- **Пакетная обработка**: задать инструкции для выполнения над большими наборами объектов,
  чтобы автоматизировать повторяющуюся работу.
- **Подтверждения**: при желании настроить уведомления, чтобы одобрять более чувствительные действия.
- **Отчёты**: получать сводку о работе, выполненной для вас в фоновом режиме.
