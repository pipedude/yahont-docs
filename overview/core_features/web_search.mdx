## Обзор {#overview}

<img className="rounded-image" src="/assets/overview/core_features/web_search.png" alt="Веб-поиск"/>

Yahont может обращаться в интернет за вопросами, требующими актуальной информации, или за узкоспециальными сведениями,
в которых LLM не уверена.

Пользователи могут включать и отключать действие **Веб-поиск** на лету, чтобы переопределить решение LLM.
Если в ходе исследования использовался [внутренний поиск](/overview/core_features/internal_search),
Yahont бесшовно объединит веб-источники с внутренними документами как при формировании ответа,
так и при отображении в интерфейсе.

## Требования {#requirements}

Для работы веб-поиска Yahont должен уметь получать результаты поиска и разбирать сайты,
чтобы получить более полный контекст. Поэтому нужны 1) *поставщик поиска* и 2) *веб-краулер*.

### Поставщики поиска {#search-providers}

Yahont предлагает несколько поставщиков поиска. Условия и цены смотрите на сайтах поставщиков:

| Название | Поставщик | Преимущество |
|------|----------|---------|
| Exa | Exa.ai | Оптимизирован для ИИ, лучше работает с семантикой. Недоступен в Yahont Cloud: Exa не работает из России. |
| Serper | Serper.dev | Быстрый и экономичный. |
| Brave | Brave Search API | Независимый поисковый индекс с хорошим охватом веба и простой настройкой через API. |
| Google PSE | Google | Официальные результаты поиска Google, надёжный вариант для команд, заботящихся о безопасности. Недоступен в Yahont Cloud: Google закрыл API для новых клиентов. |
| Tavily | Tavily | Поиск и чтение страниц, рассчитанные на ИИ-агентов. |
| SearXNG | SearXNG | Метапоиск для самостоятельного размещения, объединяющий несколько поисковых систем и сохраняющий приватность запросов. |
| srezai.ru | srezai.ru | Работает в России без VPN. Поиск и чтение страниц, русскоязычные запросы определяются автоматически. |

### Веб-краулеры {#web-scrapers}

Поскольку поставщики поиска отдают только короткие фрагменты и метаданные,
краулер используется для получения полного содержимого сайта, чтобы ответы были более полными и надёжными.

| Название | Требует настройки | Преимущества |
|------|----------------|----------|
| Onyx Web Crawler | Нет | Встроенный краулер, который подходит для большинства страниц, оставляет запросы внутри вашего развёртывания и бесплатен. |
| Firecrawl | Да, API-ключ и базовый URL | Более производителен и лучше справляется с нестандартными случаями. |
| Exa | Да, API-ключ | Получает и суммирует содержимое страниц через Exa для команд, которые уже используют Exa как поставщика поиска. |
| Tavily | Да, API-ключ | Читает страницы через Tavily для команд, которые уже используют Tavily как поставщика поиска. |
| srezai.ru | Да, API-ключ | Читает страницы через srezai.ru. Ключ общий с поиском srezai.ru. |
