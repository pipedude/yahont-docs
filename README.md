# Документация Yahont

Исходники документации [Yahont](https://yahont.ai), которая публикуется на [docs.yahont.ai](https://docs.yahont.ai).
Документация написана на русском языке для Mintlify и основана на документации открытого проекта
[Onyx](https://github.com/onyx-dot-app/onyx), на котором построен Yahont CE.

Навигация и настройки сайта лежат в `docs.json`. Страницы — файлы `.mdx`.

## Предпросмотр

Установите [Mintlify CLI](https://www.npmjs.com/package/mint) (нужен Node.js 18 или новее):

```bash
npm i -g mint
```

Запустите предпросмотр в каталоге, где лежит `docs.json`:

```bash
mint dev
```
