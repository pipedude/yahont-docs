От нуля до работающей вики, которую может читать и в которую может писать ваш агент для программирования.
Закладывайте около пятнадцати минут, большая часть уйдёт на ожидание первой сборки.

<Steps>
  <Step title="Запустите стек">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/onyx-dot-app/agent-wiki/main/install.sh | bash
    ```

    Когда установка завершится, откройте `http://localhost:8090`. Требования, ручной способ и устранение неполадок см.
    в разделе [Docker Compose](/agent-wiki/deployment/docker_compose).
  </Step>

  <Step title="Займите аккаунт администратора">
    Зарегистрируйтесь по этому адресу. **Первый созданный аккаунт становится администратором**, поэтому сделайте это,
    прежде чем к инстансу получит доступ кто-то ещё.
  </Step>

  <Step title="Настройте языковую модель">
    Откройте **Admin → Language Models** и добавьте поставщика.

    Пока модель не задана, ничего «умного» не происходит: агенты, триггеры и Auto Organize простаивают.
  </Step>

  <Step title="Напишите страницу">
    Откройте **Wiki** на боковой панели и создайте страницу. Страницы — это markdown в иерархии папок,
    и каждое сохранение — это коммит git, поэтому всё, что вы здесь делаете, можно восстановить.

    Напишите настоящее содержимое, а не заглушку. Следующий шаг интереснее, когда есть что читать.
  </Step>

  <Step title="Подключите агента">
    Откройте **Agents & Actions**, создайте ключ API и направьте вашего агента для программирования на вики:

    ```bash
    claude mcp add --transport http agent-wiki \
      http://localhost:8090/api/mcp \
      --header "Authorization: Bearer mcp_REPLACE_ME"
    ```

    Полную настройку для Claude Code, Cursor, Codex и Yahont Craft, а также подводный камень с порядком аргументов,
    на котором спотыкается команда выше, см. в разделе [Подключение агента](/agent-wiki/automate/mcp).
  </Step>

  <Step title="Попробуйте из агента">
    Попросите агента найти информацию в вики, прочитать написанную вами страницу и что-нибудь в неё добавить.
    Правка появится как коммит от вашего имени, видимый в истории страницы.

    Вокруг этого цикла и построен продукт: агенты загружают контекст из вики перед работой и записывают обратно то,
    что узнали.
  </Step>
</Steps>
