Подключите инстанс Yahont, и его проиндексированные документы автоматически поступят в вики.
Вместо того чтобы появиться кучей новых страниц,
встроенный агент находит подходящую существующую страницу и обновляет её.

## Настройка {#setup}

Откройте **Admin → Yahont Integration** и скопируйте два показанных там параметра подключения:
URL приёма (он заканчивается на `/api/documents/ingest`) и ключ API. Затем настройте ваше развёртывание Yahont так,
чтобы оно передавало документы с их помощью, одним из двух способов.

### Рекомендуется: хук Document Push (Enterprise) {#recommended-a-document-push-hook-enterprise}

В Yahont Enterprise Edition создайте **хук Document Push** в **Панель администратора → Хуки** в Yahont с URL приёма и
ключом API. Всё настраивается из интерфейса — без изменений развёртывания и перезапуска,
а неудачные передачи записываются в журнал выполнения хука, поэтому проблемы доставки видны.

### Альтернатива: переменные окружения (все редакции) {#alternative-environment-variables-all-editions}

Если у вас не Enterprise (или вы предпочитаете настройку через конфигурацию),
задайте параметры подключения как переменные окружения в вашем развёртывании Yahont и перезапустите его:

| Переменная | Обязательна | Что это |
| --- | --- | --- |
| `DOCUMENT_PUSH_ENDPOINT_URL` | да | URL приёма, скопированный со страницы администратора. Именно его задание включает передачу. |
| `DOCUMENT_PUSH_API_KEY` | да | Ключ API, скопированный со страницы администратора, отправляется как токен Bearer. |
| `DOCUMENT_PUSH_TIMEOUT_SECONDS` | нет | Тайм-аут одной передачи. По умолчанию 30. |

Эти два механизма взаимоисключающие, а не совместные: когда задана переменная окружения, она имеет приоритет,
а хук не используется. Сбои передачи на этом пути попадают только в журналы сервиса.

### Что передаётся {#what-gets-pushed}

В любом случае каждый документ, который **публичный** коннектор успешно проиндексировал, передаётся в вики.
Передача выполняется «отправил и забыл»:
сбой записывается в журнал на стороне Yahont и никогда не блокирует индексацию и не приводит к её ошибке.
Она также не срабатывает во время первоначального запуска коннектора с самого начала — только при последующих
инкрементальных обновлениях, что поддерживает актуальность вики без повторной отправки всего вашего корпуса.
Передача документов работает только в развёртываниях с одним тенантом.

## Настройки загрузки {#ingest-settings}

Под параметрами подключения на той же странице администратора находятся настройки конвейера на стороне вики:

- **Max document size** (по умолчанию 100 000 символов). Передачи больше этого значения отклоняются сразу —
  а поскольку передача из Yahont выполняется «отправил и забыл», отклонённый документ сам не вернётся.
  Если среди ваших источников есть длинные документы, такие как транскрипты встреч, увеличьте это значение,
  прежде чем их подключать.
- **Auto-update health.** Два ограничителя для страниц, которые обновляются слишком часто; оба считаются в
  скользящем 24-часовом окне:
  - **Default warning threshold** (по умолчанию 30 за 24 ч). Страница, превысившая его,
    создаёт событие в ленте активности и уведомляет владельца — только предупреждение, обновления продолжаются.
    Это лишь значение по умолчанию для всей вики:
    владельцы могут переопределить его для страницы на панели [политики
    обновления](/agent-wiki/using/update_policies#update-health) страницы.
  - **Auto-update cap** (по умолчанию 100 за 24 ч). Жёсткий лимит. Для страницы, превысившей лимит,
    последующие обновления загрузки пропускаются, пока её 24-часовой счётчик снова не опустится ниже. Задайте 0,
    чтобы отключить лимит.

## Как обрабатываются входящие документы {#how-incoming-documents-are-handled}

Переданное содержимое сопоставляется с существующими страницами и объединяется с ними — именно это делает вики живым
источником истины, а не архивом всего, что когда-либо видели ваши коннекторы.

Этим управляют два параметра:

- **Политики обновления.** Страница или папка с выключенным [обновлением](/agent-wiki/using/update_policies) никогда не
  перезаписывается загрузкой. Так защищаются записи, которые не должны меняться постфактум.
- **Инструкции страницы.** Свободные указания,
  которые учитывает обновляющий агент при редактировании — *«делайте записи краткими»*,
  *«никогда не трогайте таблицу SLA»*.

Конвейер не обязан работать на модели по умолчанию.
Здесь можно выбрать модель только для загрузки из числа включённых в разделе [Языковые
модели](/agent-wiki/admin/language_models) — и поскольку загрузка — это объёмная фоновая работа,
обычно правильный выбор — более дешёвая модель (например, Luna), чем модель по умолчанию для ежедневной работы.

<Warning>
  **Передавайте только источники, публичные для организации.** Загрузка в вики пока не учитывает права:
  содержимое из коннектора с синхронизацией прав или приватного коннектора Yahont попало бы в вики без своих ограничений
  доступа. Не включайте такие коннекторы в загрузку в вики, пока это не изменится,
  — загрузка с учётом прав есть в планах развития и скоро появится.
</Warning>
