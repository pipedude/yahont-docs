Agent Wiki нужен поставщик языковых моделей. Пока он не настроен, агенты,
триггеры и Auto Organize простаивают — ошибки нет, они просто ничего не делают.

Откройте **Admin → Language Models**, чтобы управлять учётными данными поставщика и задать модель,
которую используют агенты.

## Что здесь делает модель {#what-the-model-does-here}

Модель выполняет больше работы, чем окно чата. Она:

- Оценивает условия [триггеров](/agent-wiki/automate/triggers), написанные обычным языком, при каждом значимом изменении
- Пишет текст уведомления, которое отправляет триггер, опираясь на то, что действительно изменилось
- Применяет обновления документов, описанные естественным языком, включая те, что агенты запрашивают по MCP
- Объединяет одновременные правки, когда два автора меняют одну страницу
- Оценивает и применяет предложения [Auto Organize](/agent-wiki/automate/auto_organize)

Поэтому выбор поставщика и лимиты запросов влияют на отзывчивость всего продукта, а не одной функции.

<Note>
  **Выбор модели.** Здесь стоит взять мощную модель: она стоит за чатом,
  оценкой триггеров и каждой автоматической правкой. Затраты остаются разумными,
  потому что единственная по-настоящему многообъёмная задача — загрузка (ingestion)
  — может работать на собственной более дешёвой модели (ниже).
</Note>

## Более дешёвая модель для загрузки {#a-cheaper-model-for-ingestion}

Загрузка создаёт больше вызовов модели, чем всё остальное вместе взятое,
а её работа — сопоставление переданных документов со страницами и их объединение — не требует вашей самой сильной
модели. На странице [Интеграция с Yahont](/agent-wiki/admin/yahont_integration)
можно выбрать отдельную модель только для конвейера загрузки; выберите дешёвую и быструю (например, Luna)
и оставьте более мощную модель по умолчанию для ежедневной работы. Модель для загрузки должна быть из числа поставщиков,
включённых здесь.

## Переопределения для пользователей {#per-user-overrides}

Пользователи могут выбрать другую модель для своих чатов в **Settings**.
Настройка администратора — значение по умолчанию и модель, которую используют все автоматические процессы;
переопределение влияет только на интерактивные сессии этого человека.
