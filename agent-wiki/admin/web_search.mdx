По умолчанию агенты знают только то, что есть в вики.
**Admin → Web Search** подключает их к публичному вебу через двух поставщиков, у каждого свой ключ API:

- **[Serper](https://serper.dev)** отвечает на поисковые запросы — на нём работает инструмент `web_search`.
- **[Firecrawl](https://firecrawl.dev)** получает полное содержимое страниц — на нём работает
  инструмент `open_urls`, поэтому агент может действительно прочитать результат, а не только увидеть его фрагмент.

Ключи хранятся в базе данных в зашифрованном виде и никогда не возвращаются в браузер.

## Что это открывает {#what-it-unlocks}

Когда ключи заданы, агенты могут опираться в работе на источники вне вики — проверить утверждение,
прежде чем записать его на страницу,
получить подробности из связанного тикета или объявления либо ответить на вопросы чата,
на которые вики одна ответить не может.

Каждая возможность зависит от своего ключа: если настроен только Serper, агенты могут искать,
но не открывать результаты; если только Firecrawl — могут открывать уже известные URL, но не искать их.
Отсутствие ключа не вызывает ошибок — соответствующий инструмент просто не предлагается агентам,
так же как [функции ИИ простаивают](/agent-wiki/admin/language_models) без поставщика моделей.
