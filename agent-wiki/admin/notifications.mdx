Два канала доставки, которые администратор настраивает один раз,
после чего пользователи могут направлять на них собственные [триггеры](/agent-wiki/automate/triggers).

## Приложение Slack {#slack-app}

В **Admin → Slack App** сохраните учётные данные OAuth приложения Slack для Agent Wiki — они находятся в **Basic
Information → App Credentials** на `api.slack.com`.

Процесс **Connect Slack** скрыт от пользователей, пока не сохранены оба значения.
После этого каждый человек подключает собственный аккаунт Slack в **Settings → Connectors** и затем может отправлять
срабатывания триггеров в любой канал, в который может писать, или в личные сообщения.

Отдельные пользователи могут нажать **Mute** для своего подключения, чтобы приостановить доставку в Slack,
не отключая его, — срабатывания по-прежнему записываются в Activity Center.

## Исходящая почта {#outbound-email}

В **Admin → Outbound Email** настройте учётную запись SMTP, через которую проходит вся почта вики:
уведомления триггеров, ссылки для подтверждения и письма-уведомления.

Отправка остаётся **выключенной**, пока не сохранены хост и адрес отправителя.
До этого ссылки для подтверждения адреса тоже не приходят — стоит знать,
если вы поднимаете инстанс с регистрацией по почте и не понимаете, почему никто не может подтвердить свой адрес.

## Связанное {#related}

Оба канала появляются как адресаты при создании триггера наряду с Activity Center, вебхуками и Yahont Craft. См.
[Триггеры](/agent-wiki/automate/triggers).
