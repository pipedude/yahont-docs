Удаление в Agent Wiki обратимо. Удалённая страница или папка попадает в **Trash**,
где остаётся доступной для восстановления **30 дней**, а затем автоматически удаляется.

Откройте **Trash** на левой боковой панели, чтобы увидеть всё удалённое; для каждого элемента доступны два действия:

- **Restore** — возвращает элемент на прежнее место.
- **Delete permanently** — удаляет его немедленно, не дожидаясь 30 дней.

## Почему это важнее обычного {#why-this-matters-more-than-usual}

Корзина делает безопасной автоматизацию всего остального в продукте. Поскольку удаление обратимо:

- Агентам, подключённым по [MCP](/agent-wiki/automate/mcp), вообще разрешено удалять страницы — `delete_doc` — это
  перемещение в корзину, а не необратимое удаление.
- [Auto Organize](/agent-wiki/automate/auto_organize) может применять одобренные очистки, не будучи безупречным,
  потому что ошибочное удаление отменяется одним щелчком.

Удаление папок — осознанное исключение: агенты могут удалять страницы, но не папки. Масштаб последствий больше,
поэтому это остаётся действием человека.

## Что происходит с удалённой страницей {#what-happens-to-a-deleted-page}

Страница в корзине исключается из поиска и из живой вики, а её права,
комментарии и политика обновления следуют за ней в расположение корзины, а не отбрасываются.
При восстановлении всё возвращается вместе.

Ссылки и идентичность тоже учтены. У каждой страницы есть стабильный ID за её путём,
поэтому восстановленная страница — та же страница, а не похожая на неё по тому же адресу.

## Полезно знать {#good-to-know}

- **30 дней — это минимум, а не обещание видимости.** Элемент, удалённый по истечении срока, исчезает из корзины;
  восстановить его тогда можно только из резервной копии.
- **Страница, созданная заново по пути удалённой, — новая страница.** Она получает новую идентичность, а не наследует
  историю удалённой, поэтому позднее восстановление оригинала не объединит их.
- **История сохраняется в любом случае.** Вики основана на git,
  поэтому даже у окончательно удалённой страницы прошлые коммиты остаются в истории репозитория.
