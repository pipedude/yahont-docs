Не каждую страницу нужно переписывать автоматически. **Регламент релиза**,
который вы хотите поддерживать актуальным из подключённых источников, сильно отличается от **протокола встречи**,
который не должен меняться постфактум.

Политики обновления — способ провести эту черту. У любой страницы — или целой папки — есть политика,
которая редактируется на панели **Update Policy**.

## Переключатели {#the-switches}

Вверху панели **AI Auto-Edits** — главный переключатель: выключите его, и ИИ не будет трогать страницу самостоятельно,
точка. Он приостанавливает два переключателя ниже, не стирая их настройки,
поэтому при повторном включении ваш выбор Update/Organize восстанавливается точно таким, каким был.

Под ним два переключателя, управляющие действительно разными вещами:

| Переключатель | Чем управляет |
| --- | --- |
| **Update** | Может ли загрузка периодически сканировать ваши подключённые источники данных и добавлять на эту страницу релевантную новую информацию |
| **Organize** | Может ли [Auto Organize](/agent-wiki/automate/auto_organize) реорганизовывать, перемещать или объединять эту страницу или папку |

Выключение **Update** замораживает содержимое от передач загрузки.
Выключение **Organize** не пускает в эту область структурные очистки. У страницы вполне может быть один включён,
а другой выключен — например, журнал только для добавления, который вы хотите пополнять загрузкой,
но никогда не объединять с соседней страницей.

<Note>
  Ни один из переключателей не влияет на то, что можете делать *вы* или агент, действующий от вашего имени.
  Они ограничивают нежелательные изменения по инициативе ИИ — человек или агент,
  которого вы попросили отредактировать страницу, по-прежнему редактирует её как обычно.
</Note>

## Инструкции страницы {#page-instructions}

Под переключателями **Page Instructions** — свободный текст,
который обновляющий агент учитывает при любом редактировании:

- *«Делайте записи краткими — по одной строке.»*
- *«Никогда не трогайте таблицу SLA.»*
- *«Новые записи сверху.»*

Это указание для пишущего, а не фильтр того, что можно писать.
Это подходящее место для стиля оформления и для того единственного правила об этой странице,
которое агент иначе нарушил бы.

## Наследование {#inheritance}

Политики хранятся по путям и наследуются вниз по дереву:

- Настройка папки применяется к каждой странице под ней.
- Более конкретная страница или подпапка переопределяет родителя.
- Сброс настройки возвращает то, что говорит родитель.

Поэтому обычный приём — задать намерение один раз для папки — *«ничего в `decisions/` не реорганизовывать»* — и
переопределять только исключения. Страница без настроек просто берёт ближайшего предка, у которого есть мнение,
вплоть до корня вики.

Поскольку политики живут по путям, а не в теле страницы, эти указания не просачиваются в содержимое,
и они переживают правки любого пользователя.

## Здоровье обновлений {#update-health}

Карточка **Update History** внизу панели показывает,
как часто страница автоматически редактировалась за последние 24 часа, относительно двух лимитов:

- **Alert.** Когда страница превышает это число автообновлений за 24 часа, событие попадает в ленту
  активности, а владелец страницы получает уведомление — только предупреждение, страница продолжает обновляться.
  Число берётся из значения по умолчанию для всей вики,
  которое администратор задаёт на странице [Интеграция с Yahont](/agent-wiki/admin/yahont_integration#ingest-settings);
  владелец страницы может переопределить его здесь для страниц,
  где частые изменения ожидаемы (или особенно нежелательны).
- **Auto-Edit Limit.** Жёсткий лимит, который администратор задаёт для всей вики. Для страницы, превысившей лимит,
  последующие обновления загрузки пропускаются,
  пока её скользящий 24-часовой счётчик снова не опустится ниже — страница-«беглец» не может расходовать бюджет модели
  или заваливать собственную историю.

В отличие от переключателей, порог оповещения задаётся только для страницы — он не наследуется вниз по папкам.

## Настройка политик из агента {#setting-policies-from-an-agent}

Агенты, подключённые по [MCP](/agent-wiki/automate/mcp), могут читать и задавать политики с помощью `set_update_policy`,
поэтому вы можете сказать «перестань автообновлять эту папку» в разговоре, а не открывать панель.
Агент действует от вашего имени, поэтому он может менять политики только на тех путях, которые можете менять вы сами.

## Полезно знать {#good-to-know}

- **Перемещения переносят политику.** Переименование или перемещение страницы сохраняет её политику,
  поэтому реорганизация не откроет страницу для автоматических правок незаметно.
- **Шаблоны могут нести значения по умолчанию.** Администратор может задать стартовую политику для
  [шаблона](/agent-wiki/admin/templates), чтобы созданные из него страницы сразу получали правильную настройку,
  а не требовали последующей правки.
