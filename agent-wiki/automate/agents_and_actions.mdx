Раздел **Agents & Actions** на левой боковой панели — это место, где вы управляете ключами,
позволяющими агентам читать и обновлять вашу вики, и где настраивается лаунчер.

## Ключи API {#api-keys}

Нажмите **Create**, назовите ключ по имени устройства или агента, который будет его хранить,
и скопируйте значение `mcp_…`. Оно показывается один раз — если вы его потеряете,
создайте другой ключ и отзовите старый.

Ключи привязаны к пользователю, а агент с таким ключом действует **от вашего имени, с вашими правами**.
Он читает ровно те страницы, которые можете читать вы, и пишет ровно туда, куда можете писать вы. Ключ,
созданный администратором, — ключ администратора, поэтому создавайте ключи из аккаунта,
доступ которого действительно должен быть у агента.

**Revoke** действует немедленно: любой агент, использующий этот ключ, перестаёт работать.

Называть ключи по устройствам, а не использовать один и тот же,
стоит небольших усилий — это единственный способ отозвать доступ потерянного ноутбука,
не сломав всех остальных подключённых агентов.

## Подключение агента {#connecting-an-agent}

Конечная точка — это источник вашей вики с добавлением `/api/mcp`. Настройка для Claude Code, Cursor,
Codex и Yahont Craft — вместе с подводным камнем с порядком аргументов, на котором спотыкается команда Claude Code,
— описана в разделе [Подключение агента](/agent-wiki/automate/mcp), там же полный список инструментов,
которые получает агент.

## Лаунчер {#launcher}

**Set up launcher** устанавливает лаунчер Run-Agent для вашей платформы — macOS, Linux или Windows,
— чтобы вики могла передать страницу прямо в локальную сессию агента.
Страница определяет вашу платформу и предлагает подходящий установщик.

<Note>
  Сборка для Windows пока не подписана, поэтому при первом запуске Windows может показать предупреждение SmartScreen.
</Note>

## Что агент может делать после подключения {#what-an-agent-can-do-once-connected}

Искать и читать страницы, редактировать и создавать их, перемещать элементы, участвовать в обсуждениях в комментариях,
задавать политики обновления и удалять страницы в [корзину](/agent-wiki/using/trash).
Каждая запись — обычный коммит git от вашего имени, видимый в истории страницы,
поэтому работу агента можно проверить и отменить так же, как работу любого другого.
