## Как это работает {#how-it-works}

Коннектор YouTrack индексирует задачи и их комментарии. У каждой задачи в метаданных есть проект,
её публичные пользовательские поля (состояние, приоритет, исполнитель и другие) и, после решения, время решения.
Автор задачи записывается как её владелец.

Yahont проверяет YouTrack на новые и изменённые задачи каждые **30** минут.

| Содержимое  | Примечания                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------------- |
| Задачи      | Заголовок и описание вместе с комментариями задачи. Удалённые комментарии и комментарии с собственным ограничением видимости пропускаются. Архивные проекты пропускаются. |
| Область     | Необязательно. Ограничьте индекс отдельными проектами по краткому имени.                                   |
| Права       | Необязательно в Yahont Cloud и Enterprise Edition. Yahont повторяет, кто видит каждую задачу в YouTrack.   |

Коннектор поддерживает YouTrack Cloud и YouTrack Server.
Для **Синхронизировать с YouTrack** нужен YouTrack 2026.1 или новее.

## Настройка {#setting-up}

### Авторизация {#authorization}

Коннектор входит по постоянному токену. Yahont видит ровно то, что видит пользователь токена,
поэтому дайте этому пользователю права **Read Issue** и **Read Issue Comment** в каждом проекте,
который хотите индексировать.
Для **Синхронизировать с YouTrack** дополнительные права пользователя токена описаны в разделе [Синхронизация с
YouTrack](#sync-with-youtrack).

<Steps>
  <Step title="Откройте профиль YouTrack">
    В YouTrack нажмите на аватар и откройте профиль, затем откройте вкладку **Account Security**.
  </Step>

  <Step title="Создайте постоянный токен">
    В разделе **Tokens** выберите **New token...**. Задайте токену название,
    оставьте выбранным scope **YouTrack** и выберите **Create**.
  </Step>

  <Step title="Скопируйте токен">
    Скопируйте токен сейчас. YouTrack показывает его только один раз.
  </Step>
</Steps>

### Индексация {#indexing}

<Steps>
  <Step title="Откройте коннектор YouTrack">
    В интерфейсе Yahont откройте панель администратора и выберите коннектор **YouTrack**
  </Step>

  <Step title="Введите адрес YouTrack">
    Введите адрес вашего YouTrack, например `https://example.youtrack.cloud`.
    Для YouTrack Server укажите контекстный путь, например `https://example.com/youtrack`.
  </Step>

  <Step title="Подключите аккаунт YouTrack">
    Выберите **New YouTrack Account** и вставьте постоянный токен. Токен сохраняется вместе с коннектором.
  </Step>

  <Step title="Выберите, что индексировать">
    Оставьте **Projects** пустым, чтобы индексировать все проекты, которые может читать пользователь токена.
    Чтобы сузить индекс, введите краткие имена проектов, например `ABC`.

    Yahont проверяет каждую запись перед созданием коннектора и называет проекты, о которых YouTrack не отвечает.
    Это значит, что краткое имя неверно или у пользователя токена нет доступа к проекту.
  </Step>

  <Step title="Выберите, кто видит задачи">
    - **Все в вашей организации** делает каждую проиндексированную задачу видимой каждому пользователю Yahont.
    - **Определённые группы** ограничивает коннектор выбранными группами Yahont.
    - **Синхронизировать с YouTrack** повторяет собственный доступ YouTrack и доступно в Yahont Cloud и
    Enterprise Edition.
  </Step>

  <Step title="Проверьте проверки подключения">
    Когда аккаунт выбран, Yahont запускает проверки в YouTrack и перечисляет каждую в форме.
    **Создать коннектор** становится доступной, когда обязательные проверки пройдены. Непройденная проверка называет,
    что исправить.
  </Step>

  <Step title="Создайте коннектор">
    Нажмите `Создать коннектор`, чтобы начать индексацию задач и комментариев YouTrack!
  </Step>
</Steps>

### Проверки подключения {#connection-checks}

Каждая проверка читает данные из YouTrack с токеном, поэтому сбой указывает на доступ пользователя токена.

| Проверка                                                | Проходит, когда                                                          | Не проходит, когда                                                                                   |
| ------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| YouTrack принимает адрес и токен                        | YouTrack отвечает для пользователя токена                                | Адрес неверен, в адресе YouTrack Server нет контекстного пути или токен недействителен или отозван   |
| Указанные проекты доступны для чтения                   | Каждое введённое краткое имя существует для пользователя токена          | Краткое имя написано с ошибкой или у пользователя токена нет доступа к проекту                       |
| Задачи и комментарии доступны для чтения                | Одна задача из области возвращается вместе с комментариями               | У пользователя токена нет Read Issue или Read Issue Comment                                          |
| Пользователь токена читает каждую задачу, в том числе с ограничениями | У пользователя токена есть Override Visibility Restrictions в каждом проекте | У пользователя токена нет Override Visibility Restrictions в проекте из области или он не может читать назначения ролей |
| Настройки видимости задач доступны для чтения           | Одна задача из области возвращается с настройками **Visible to**         | У пользователя токена нет Read Issue в проекте из области                                            |
| Email пользователей доступны для чтения                 | YouTrack перечисляет пользователей с их email                            | YouTrack скрывает email от пользователя токена, поэтому ни одного пользователя YouTrack нельзя сопоставить с пользователем Yahont |

Проверки токена и задач выполняются для каждого коннектора, а проверка проектов — всякий раз,
когда введены краткие имена.
Остальные выполняются только с **Синхронизировать с YouTrack** и запускаются снова перед каждой плановой синхронизацией
прав, поэтому токен, потерявший доступ, останавливает синхронизацию, а не скрывает задачи.

Если в области ещё нет ни одной задачи, проверка задач проходит с примечанием, что доступ к комментариям не проверялся.

## Синхронизация с YouTrack {#sync-with-youtrack}

С **Синхронизировать с YouTrack** пользователь Yahont находит задачу, только если её видит его аккаунт YouTrack,
сопоставленный по email:

- Задача видна всем, у кого в её проекте есть и **Read Issue**, и **Read Issue Comment**,
  через роль проекта, организации или глобальную роль, группу или команду проекта.
- Задача с ограничением **Visible to** видна только перечисленным пользователям и группам, у которых в проекте есть те
  же права, а также автору и тем из них, у кого есть **Override Visibility Restrictions**.
- В проекте службы поддержки заявка видна пользователям и группам, указанным в её видимости, и её автору,
  роль проекта не нужна. Аккаунты клиентов никогда не видят заявки через роли проекта.
- Заблокированные пользователи не видят ничего. Задачи никогда не открываются всем пользователям Yahont, потому что
  задачи YouTrack никогда не читаются без входа.

Пользователь токена должен читать каждую задачу из области, в том числе с ограничениями,
и читать назначения ролей и группы, которые YouTrack показывает только администраторам.
Используйте постоянный токен пользователя **System Admin** или пользователя с **Low-level Admin Read** плюс **Read
Issue**, **Read Issue Comment** и **Override Visibility Restrictions** в каждом проекте для синхронизации.
