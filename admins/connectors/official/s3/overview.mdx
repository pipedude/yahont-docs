## Как это работает {#how-it-works}

Коннектор S3 получает все документы из указанной корзины Amazon S3. Он поддерживает различные форматы файлов,
включая PDF, DOC, DOCX, TXT и другие.

Документы обновляются раз в **1** день.

## Настройка {#setting-up}

### Авторизация {#authorization}

Мы поддерживаем три метода авторизации — выберите подходящий для вашей среды:

- [Ключи доступа AWS](./access-keys) — использует традиционные учётные данные с ключами доступа
- [Авторизация на основе роли IAM](./iam-role) — использует роли AWS IAM для безопасного доступа
- [Assume Role](./assume-role) — автоматически использует роль, прикреплённую к инстансу EC2, для доступа к S3

### Индексирование {#indexing}

После настройки метода авторизации выполните следующие шаги, чтобы проиндексировать корзину S3:

<Steps>
  <Step title="Откройте коннектор S3">
    Откройте панель администратора Yahont и выберите коннектор **S3**.
  </Step>

  <Step title="Настройте авторизацию">
    На **шаге 1** настройте авторизацию:
    - Если у вас есть учётные данные, выберите их из списка
    - Если учётных данных нет, нажмите **Create New**, чтобы добавить новую авторизацию:
    - **Access Keys**: введите AWS Access Key ID и Secret Access Key
    - **IAM Role**: откройте вкладку IAM Role и введите Role ARN
    - **Assume Role**: откройте вкладку Assume Role (учётные данные не требуются)
  </Step>

  <Step title="Сохраните конфигурацию">
    Нажмите **Create**, чтобы сохранить конфигурацию.
  </Step>

  <Step title="Продолжите с выбранными учётными данными">
    Убедитесь, что выбраны нужные учётные данные, и нажмите **Continue**
  </Step>

  <Step title="Укажите сведения о корзине">
    На **шаге 2** укажите сведения о вашей корзине S3:
    - **Connector Name**: введите название коннектора (например, «MyS3Connector»)
    - **Bucket Name**: укажите имя корзины S3, которую хотите индексировать
    - **Prefix (Optional)**: укажите префикс, чтобы ограничить индексацию определённой папкой или путём
    - **Access Type**: выберите, будут ли документы **Public** или **Private**
  </Step>

  <Step title="Создайте коннектор">
    Нажмите **Create Connector**, чтобы начать индексацию.
  </Step>
</Steps>

Коннектор начнёт индексировать вашу корзину S3, а позже можно добавить другие корзины или изменить настройки.

## Как устроено хранилище S3 {#understanding-s3-structure}

Amazon S3 организует данные в корзины (buckets). В каждой корзине может быть неограниченное число объектов (файлов).
Корзину можно представить как корневой каталог, а объекты — как файлы в этом каталоге.

Подробнее о структуре S3 читайте в [документации Amazon
S3](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html).
