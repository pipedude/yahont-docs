## Как это работает {#how-it-works}

Коннектор Zendesk может синхронизировать содержимое вашего инстанса Zendesk и поддерживает два типа содержимого:

- **Статьи**: синхронизирует все опубликованные статьи из Справочного центра (Help Center) вашей компании
- **Заявки**: синхронизирует заявки в поддержку (Support Tickets) с комментариями и метаданными

Коннектор поддерживает инкрементальные обновления и сохраняет сведения об авторе, теги содержимого и другие метаданные.

## Типы содержимого {#content-types}

### Статьи {#articles}

- Синхронизирует все опубликованные статьи из Справочного центра Zendesk
- Включает содержимое статей, метки и теги содержимого
- Отслеживает сведения об авторе и время обновления
- Пропускает черновики и статьи с определёнными пропускаемыми метками (настраивается)

### Заявки {#tickets}

- Синхронизирует заявки в поддержку с полными цепочками комментариев
- Включает метаданные заявки (статус, приоритет, теги, тип)
- Отслеживает сведения об авторе и комментаторах
- Исключает удалённые заявки
- **Примечание**: требуется активный продукт Zendesk Support

## Текущие ограничения {#current-limitations}

- Статьи: нельзя фильтровать по отдельным категориям или разделам
- Заявки: требуется активный продукт Zendesk Support

## Настройка {#setting-up}

### Авторизация {#authorization}

Для подключения коннектору Zendesk нужны 3 значения:
- **Subdomain**: ваш поддомен Zendesk (например, `your-company` из `your-company.zendesk.com`)
- **Email**: адрес электронной почты владельца API-токена
- **API Token**: API-токен Zendesk для аутентификации

### Индексирование {#indexing}

<Steps>
  <Step title="Добавьте коннектор Zendesk">
    Откройте **панель администратора**, выберите `Добавить коннектор`, затем плитку Zendesk
  </Step>

  <Step title="Выберите тип содержимого">
    Выберите тип содержимого (Articles или Tickets)
  </Step>

  <Step title="Укажите данные аутентификации">
    Укажите данные аутентификации из раздела выше
  </Step>

  <Step title="Запустите синхронизацию">
    Нажмите «Подключить», чтобы начать синхронизацию содержимого из Zendesk
  </Step>
</Steps>

Коннектор выполняет инкрементальные синхронизации, чтобы содержимое оставалось актуальным,
используя постраничную выдачу на основе курсора для статей и получение по меткам времени для заявок.

## Метаданные {#metadata}

Коннектор извлекает и индексирует следующие метаданные:

### Статьи {#articles}

- Метки (labels статей)
- Теги содержимого
- Сведения об авторе
- Время обновления

### Заявки {#tickets}

- Статус (open, pending, solved и т. д.)
- Уровень приоритета
- Теги
- Тип заявки
- Сведения об отправителе
- История комментариев с авторами и временем
