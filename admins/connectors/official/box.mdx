Коннектор Box индексирует файлы, к которым есть доступ у сервисного аккаунта Box или управляемого пользователя.
Можно индексировать всё, что видно этой учётной записи, или ограничиться отдельными папками.

## Как это работает {#how-it-works}

| Содержимое  | Поведение                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------- |
| Файлы       | Yahont извлекает и индексирует поддерживаемые типы документов, их ссылки Box, владельцев, метки времени и пути папок. |
| Папки       | Yahont сохраняет иерархию папок для просмотра и фильтрации.                                                          |
| Веб-ссылки  | Необязательно. Yahont индексирует название закладки, описание и целевой URL; страница назначения не сканируется.     |
| Права       | Необязательно в Yahont Cloud и Enterprise Edition. Yahont может синхронизировать владельцев Box, совместную работу, группы и общие ссылки. |

При каждом обновлении коннектор рекурсивно перечисляет все папки в настроенной области,
затем загружает и обрабатывает только файлы и веб-ссылки, изменённые в окне индексации.
Для большого дерева Box выберите отдельные папки и частоту обновления, подходящую вашей пропускной способности API Box.

## Перед началом {#before-you-begin}

Вам понадобятся:

- Доступ к [Box Developer Console](https://app.box.com/developers/console)
- Администратор или соадминистратор Box, который может авторизовать Platform App с серверной аутентификацией
- Аккаунт администратора Yahont
- Адрес электронной почты управляемого пользователя Box, если вы планируете индексировать от его имени

<Note>
  Обычный аккаунт Box Individual не даёт корпоративных возможностей, необходимых для этой настройки.
  Используйте корпоративный аккаунт Box, аккаунт разработчика или песочницу разработчика.
</Note>

## Выбор удостоверения для доступа к содержимому Box {#choose-the-box-content-identity}

Коннектор может получать доступ к содержимому Box одним из двух способов:

| Удостоверение           | Когда использовать                                                            | Подготовка в Box                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Управляемый пользователь** | Индексировать файлы и папки, видимые в представлении **All Files** существующего пользователя. | Введите адрес электронной почты пользователя в Yahont и включите **Generate user access tokens** для приложения Box. |
| **Сервисный аккаунт приложения** | Индексировать только содержимое, которым намеренно поделились с интеграцией.    | Оставьте адрес электронной почты пользователя пустым и добавьте сервисный аккаунт приложения соучастником каждой начальной папки. |

Идентификатор папки `0` означает корневую папку выбранного удостоверения.
Это не глобальный корень со всеми приватными файлами Box всех пользователей.

## Настройка Box {#configure-box}

<Steps>
  <Step title="Создайте Platform App">
    В [Box Developer Console](https://app.box.com/developers/console) выберите **Platform Apps → New App**.
    Создайте **Custom App** с **Server Authentication (Client Credentials Grant)**. Дайте ему узнаваемое имя,
    например `Yahont Connector`.
  </Step>

  <Step title="Задайте уровень доступа и области">
    На вкладке **Configuration** приложения установите **App Access Level** в **App + Enterprise Access**.

    Включите области в зависимости от функций, которые вы будете использовать:

    | Настройка Box | Когда нужна |
    | --- | --- |
    | **Read all files and folders stored in Box** | Всегда |
    | **Manage users** | При использовании адреса электронной почты управляемого пользователя или автосинхронизации прав |
    | **Manage groups** | При использовании автосинхронизации прав |

    <Note>
      Эти области позволяют приложению вызывать необходимые API.
      Выбранный сервисный аккаунт или управляемый пользователь всё равно должен иметь доступ к каждому файлу и папке,
      которые вы хотите, чтобы Yahont проиндексировал.
    </Note>
  </Step>

  <Step title="Включите доступ управляемого пользователя">
    Если вы будете вводить в Yahont адрес электронной почты управляемого пользователя,
    включите **Generate user access tokens** в расширенной или дополнительной конфигурации приложения.
    Можно оставить выключенным, если используется только сервисный аккаунт приложения.
  </Step>

  <Step title="Сохраните и авторизуйте приложение">
    Сохраните конфигурацию.
    Авторизуйте приложение в Developer Console или отправьте его на авторизацию администратору или соадминистратору Box.

    Администратор также может авторизовать его в **Admin Console → Integrations → Platform Apps Manager → Server
    Authentication Apps**, добавив Client ID приложения.

    <Warning>
      Авторизация Box фиксирует конфигурацию приложения на этот момент.
      Если позже вы измените его области или уровень доступа, администратор должен повторно авторизовать приложение,
      чтобы изменения вступили в силу.
    </Warning>
  </Step>

  <Step title="Скопируйте учётные данные">
    В настройках приложения скопируйте **Client ID**, **Client Secret** и **Enterprise ID**.

    Box требует двухфакторную аутентификацию в вашем аккаунте, прежде чем покажет client secret.
    Считайте секрет конфиденциальным и не помещайте его в систему контроля версий.
  </Step>
</Steps>

Подробнее об этих настройках Box см.
в [руководстве по настройке Client Credentials
Grant](https://developer.box.com/guides/authentication/client-credentials/client-credentials-setup/)
и [руководстве по одобрению Platform App](https://developer.box.com/guides/authorization/platform-app-approval/) от Box.

## Настройка Yahont {#configure-onyx}

<Steps>
  <Step title="Откройте коннектор Box">
    В Yahont откройте **Панель администратора → Добавить коннектор** и выберите **Box**.
  </Step>

  <Step title="Введите учётные данные Box">
    Создайте учётные данные и введите значения, скопированные из Box:

    | Поле Yahont | Значение |
    | --- | --- |
    | **Box Client ID** | Client ID приложения Platform App |
    | **Box Client Secret** | Client Secret приложения Platform App |
    | **Box Enterprise ID** | Идентификатор вашей корпоративной учётной записи Box |
    | **Email of Box user to impersonate (optional)** | Точный адрес электронной почты для входа управляемого пользователя или пусто, чтобы использовать сервисный аккаунт приложения |
  </Step>

  <Step title="Выберите папки для индексации">
    Задайте коннектору название.
    В поле **Folders** введите один или несколько идентификаторов папок Box или полных URL папок,
    например `https://app.box.com/folder/123456789`.

    Оставьте **Folders** пустым, чтобы индексировать всё, что видно из корневой папки выбранного удостоверения.
    Каждая настроенная папка индексируется рекурсивно.
  </Step>

  <Step title="Выберите параметры индексации и доступа">
    В **Advanced Configuration** включите **Include Web Links**,
    если хотите индексировать закладки Box как облегчённые документы.

    Выберите тип доступа коннектора:

    - **Public** делает всё проиндексированное содержимое Box видимым каждому пользователю Yahont.
    - **Private** ограничивает весь коннектор выбранными пользователями и группами Yahont.
    - **Auto Sync Permissions** воспроизводит поддерживаемое управление доступом Box и доступна в Yahont Cloud и
    Enterprise Edition.
  </Step>

  <Step title="Подключите и проверьте">
    Нажмите **Connect**. Затем откройте **Панель администратора → Существующие коннекторы**,
    выберите коннектор и убедитесь, что первая попытка индексации завершилась.
  </Step>
</Steps>

## Автосинхронизация прав {#auto-sync-permissions}

При **Auto Sync Permissions** Yahont сопоставляет принятые совместные доступы Box с правом чтения с совпадающими
адресами электронной почты пользователей Yahont и группами Box.
Он также учитывает унаследованный доступ к папкам и общие ссылки:

- Ссылка **People with the link** без пароля считается публичной.
- Ссылка **People in your company** доступна синхронизированным пользователям корпоративной учётной записи Box.
- Совместный доступ только на загрузку не даёт права чтения в Yahont.
- Адреса электронной почты для входа в Box должны совпадать с адресами пользователей в Yahont.

У приложения Box должны быть **Manage users** и **Manage groups**,
а администратор должен повторно авторизовать приложение после добавления этих областей.

<Warning>
  Проверьте тип доступа перед подключением.
  Выбор **Public** не сохраняет права Box и может открыть проиндексированное содержимое каждому пользователю Yahont.
</Warning>

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Приложение не авторизовано или учётные данные отклонены">
    Ошибка вида `unauthorized_client: The "box_subject_type" value is unauthorized for this client_id` означает,
    что приложение не авторизовано для доступа к предприятию:
    установите **App Access Level** в **App + Enterprise Access** и попросите администратора или соадминистратора Box
    авторизовать приложение. Также убедитесь, что Client ID,
    Client Secret и Enterprise ID принадлежат одному и тому же Platform App.
    Если какая-либо настройка приложения изменилась, повторно авторизуйте его в Box Admin Console.
  </Accordion>

  <Accordion title="Управляемого пользователя не удаётся найти или аутентифицировать">
    Введите точный адрес электронной почты пользователя для входа в Box. Убедитесь,
    что пользователь управляется тем же предприятием, включены **App + Enterprise Access** и **Manage users**,
    а также **Generate user access tokens**. Повторно авторизуйте приложение после исправления любой настройки.
  </Accordion>

  <Accordion title="Папка не найдена или в ней не индексируются файлы">
    Проверьте идентификатор или URL папки и убедитесь, что выбранный управляемый пользователь может открыть папку.
    Если адрес электронной почты пользователя пуст, добавьте сервисный аккаунт приложения соучастником папки.
    Пустой корень сервисного аккаунта не включает существующее содержимое предприятия автоматически.
  </Accordion>

  <Accordion title="Синхронизация прав не работает">
    Убедитесь,
    что включены **Manage users** и **Manage groups** и что после этого приложение было повторно авторизовано.
    Также убедитесь, что вы используете Yahont Cloud или Enterprise Edition.
  </Accordion>

  <Accordion title="Обновления медленные или используют много вызовов API Box">
    Каждое обновление обходит всё настроенное дерево папок, содержимое папок перечисляется страницами до 200 элементов.
    Синхронизация прав делает дополнительные вызовы для совместного доступа к папкам и файлам, пользователей и групп.
    Ограничьте **Folders** нужными поддеревьями или увеличьте частоту обновления для очень больших развёртываний Box.
  </Accordion>

  <Accordion title="Файл или веб-ссылка отсутствует">
    Убедитесь, что удостоверение имеет доступ к элементу.
    Yahont пропускает неподдерживаемые типы файлов и файлы больше настроенного лимита размера коннектора Box,
    по умолчанию 20 МБ. Веб-ссылкам нужен **Include Web Links**, и индексируются только метаданные закладки;
    страница назначения не загружается.
  </Accordion>
</AccordionGroup>
