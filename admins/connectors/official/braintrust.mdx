Коннектор Braintrust индексирует промпты, наборы данных и эксперименты вашей организации в Braintrust,
поэтому результат оценки можно найти через поиск Yahont.

## Как это работает {#how-it-works}

| Содержимое | Поведение |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Промпты | Один документ на промпт с названием `Prompt: <name>`. |
| Наборы данных | Один документ на набор данных с названием `Dataset: <name>`, строки набора хранятся в виде таблицы. |
| Эксперименты | Один документ на эксперимент с названием `Experiment: <name>`. Сводка индексируется всегда, а результаты по строкам зависят от глубины просмотра (см. ниже). |
| Права | Недоступны. **Автосинхронизация прав** для Braintrust не предлагается, поэтому тип доступа может быть только **Публичный** или **Приватный**. |

Yahont индексирует сначала промпты, затем наборы данных, затем эксперименты и запоминает место между запусками,
поэтому большая организация индексируется за несколько попыток.

Таблица набора данных или эксперимента обрезается до **10 000 последних строк**.
В этом случае Yahont добавляет в документ строку о том, что таблица обрезана,
поэтому ограничение видно в поиске и не остаётся скрытым.

## Перед началом {#before-you-begin}

Вам понадобятся:

- Аккаунт Braintrust с доступом к организации, которую нужно индексировать
- API-ключ Braintrust
- Аккаунт администратора Yahont

<Note>
  Коннектор читает API Braintrust по адресу `https://api.braintrust.dev` и индексирует только то,
  что может прочитать API-ключ.
</Note>

## Настройка Yahont {#configure-onyx}

<Steps>
  <Step title="Откройте коннектор Braintrust">
    В Yahont перейдите в **Панель администратора → Добавить коннектор** и выберите **Braintrust**.
  </Step>

  <Step title="Создайте учётные данные">
    Вставьте ключ в поле **Braintrust API Key**.

    <img className="rounded-image" src="/assets/admins/connectors/braintrust/BraintrustCredential.png" alt="Создание учётных данных Braintrust с названием и API-ключом Braintrust"/>
  </Step>

  <Step title="Выберите область">
    Задайте название коннектора. В поле **Project Name** укажите один проект Braintrust,
    чтобы индексировать только его промпты, наборы данных и эксперименты. Оставьте поле пустым,
    чтобы индексировать всю организацию.

    Yahont проверяет название при сохранении коннектора и отклоняет проект, который не удаётся найти.
  </Step>

  <Step title="Выберите тип доступа">
    **Публичный** делает всё проиндексированное содержимое Braintrust видимым для каждого пользователя Yahont.
    **Приватный** ограничивает коннектор выбранными группами пользователей Yahont. Это функция Enterprise Edition:
    группы пользователей в Yahont CE недоступны.
  </Step>

  <Step title="Подключитесь и проверьте">
    Нажмите **Создать коннектор**. Затем откройте **Панель администратора → Существующие коннекторы**,
    выберите коннектор и убедитесь, что первая попытка индексации завершилась.
  </Step>
</Steps>

### Расширенные настройки {#advanced-settings}

| Параметр | По умолчанию | Назначение |
| ------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Experiment Row Lookback (days) | 30 | Индексировать результаты по строкам только для экспериментов, созданных за указанное число дней. Сводки экспериментов индексируются всегда. Задайте `0`, чтобы индексировать строки всех экспериментов. |

Увеличьте глубину просмотра или задайте `0`, если нужно искать по строкам старых экспериментов.
В обоих случаях каждый запуск индексации читает из Braintrust больше данных.

## Ограничения {#limits}

| Ограничение | Значение | Примечания |
| ----------------------- | -------------- | ------------------------------------------------------------------------------ |
| Строк на таблицу | 10 000 | Сохраняются последние строки, а в документе указано, что таблица обрезана. |
| Вызов API Braintrust | 60 с | |
| Повторов на запрос | 5 | |
| Частота запросов | 4 в секунду | Yahont сам ограничивает частоту, чтобы не превышать лимиты API Braintrust. |

Коннектор не скачивает файлы, поэтому ограничения на размер файла нет.

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="API-ключ отклонён">
    `Braintrust API rejected the API key` с HTTP 401 или 403 означает, что ключ неверный,
    отозван или принадлежит не той организации. Создайте новый ключ в Braintrust и обновите учётные данные в Yahont.
  </Accordion>

  <Accordion title="Проект не найден">
    `Braintrust project '<name>' was not found` означает, что **Project Name** не совпадает ни с одним проектом,
    доступным ключу. Название должно совпадать точно. Оставьте поле пустым, чтобы индексировать всю организацию.
  </Accordion>

  <Accordion title="Braintrust недоступен">
    `Failed to reach the Braintrust API` означает, что запрос не завершился. Проверьте,
    что сервер Yahont может обратиться к `https://api.braintrust.dev`, и повторите попытку.
  </Accordion>

  <Accordion title="Нет строк экспериментов">
    Строки индексируются только у экспериментов, созданных в пределах **Experiment Row Lookback (days)**;
    у более старых экспериментов остаётся только сводка. Увеличьте глубину просмотра или задайте `0`,
    затем переиндексируйте.
  </Accordion>

  <Accordion title="Большая таблица неполная">
    Таблица ограничена 10 000 последних строк, и документ сообщает об этом. Это ограничение не настраивается.
  </Accordion>
</AccordionGroup>
