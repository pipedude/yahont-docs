Коннектор Canvas индексирует опубликованные страницы, опубликованные задания и активные объявления из курсов Canvas LMS,
к которым есть доступ у настроенного токена доступа.

Выбора курсов нет. Yahont индексирует каждый **доступный** курс, который Canvas возвращает для этого токена.

## Как это работает {#how-it-works}

| Содержимое     | Поведение                                                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Страницы       | Только опубликованные страницы. Yahont индексирует заголовок и HTML-тело как текст, а также ссылку на страницу Canvas.                    |
| Задания        | Только опубликованные задания. Yahont индексирует название, HTML-описание как текст, срок сдачи (если есть) и ссылку на задание Canvas.   |
| Объявления     | Только активные объявления. Yahont индексирует заголовок, HTML-сообщение как текст и ссылку на объявление Canvas.                         |
| Курсы          | Только курсы в состоянии Canvas `available`. Неопубликованные, завершённые и удалённые курсы не перечисляются.                           |
| Права          | Необязательно в Yahont Cloud и Enterprise Edition. Yahont может синхронизировать доступ к курсам, разделам и группам Canvas по зачислениям и переопределениям. |

При каждом обновлении коннектор перечисляет доступные курсы токена, затем обрабатывает страницы,
задания и объявления в этом порядке. Страницы и задания включаются,
когда их `updated_at` в Canvas попадает в окно индексации. Объявления включаются, когда их `posted_at` попадает в окно.
Страницы без `updated_at`, задания без `updated_at` и объявления без `posted_at` пропускаются.

## Перед началом {#before-you-begin}

Вам понадобятся:

- HTTPS-URL вашего сайта Canvas, например `https://school.instructure.com`
- Пользователь Canvas, который может открыть каждый курс, который вы хотите индексировать в Yahont
- Право в Canvas создавать токен доступа API для этого пользователя
- Аккаунт администратора Yahont

<Note>
  Токен доступа имеет тот же доступ в Canvas, что и создавший его пользователь.
  Yahont индексирует только доступные курсы, опубликованные страницы, опубликованные задания и активные объявления,
  которые видит этот пользователь.
</Note>

## Настройка Canvas {#configure-canvas}

<Steps>
  <Step title="Откройте настройки аккаунта Canvas">
    В Canvas откройте **Account → Settings**. Также можно перейти напрямую на `/profile` вашего сайта Canvas.
  </Step>

  <Step title="Создайте токен доступа">
    В **Approved Integrations** выберите **New Access Token** (иногда называется **Add New Access Token**).

    Введите назначение, например `Yahont Connector`. При желании задайте срок действия. Оставляйте срок действия пустым,
    только если ваше учреждение разрешает бессрочные токены.

    Создайте токен и сразу скопируйте его. Canvas больше не покажет токен целиком.

    <Warning>
      Относитесь к токену как к паролю. Он аутентифицируется как пользователь Canvas, который его создал.
      Некоторые учреждения ограничивают, кто может создавать токены; если кнопка недоступна,
      попросите администратора Canvas предоставить разрешение **Users - manage access tokens** или создать токен за вас.
    </Warning>
  </Step>
</Steps>

Описание шагов от самого Canvas см.
в [How do I manage API access tokens in my user
account?](https://community.instructure.com/en/kb/articles/662901-how-do-i-manage-api-access-tokens-in-my-user-account)
и в [документации OAuth / токенов доступа](https://canvas.instructure.com/doc/api/file.oauth.html) Canvas.

## Настройка Yahont {#configure-onyx}

<Steps>
  <Step title="Откройте коннектор Canvas">
    В Yahont откройте **Панель администратора → Добавить коннектор** и выберите **Canvas**.
  </Step>

  <Step title="Введите токен доступа Canvas">
    Создайте учётные данные и вставьте токен в **Canvas Access Token**.

    <img className="rounded-image" src="/assets/admins/connectors/canvas/CanvasCredential.png" alt="Создание учётных данных Canvas с названием и токеном доступа Canvas"/>
  </Step>

  <Step title="Введите базовый URL Canvas">
    Задайте коннектору название. В **Canvas Base URL** введите URL сайта, например `https://school.instructure.com`.

    Используйте `https`. Не используйте `http`. Завершающий слэш и `/api/v1` можно опустить; Yahont нормализует их,
    если они указаны.

    <img className="rounded-image" src="/assets/admins/connectors/canvas/CanvasConnector.png" alt="Форма коннектора Canvas с названием коннектора и базовым URL Canvas"/>
  </Step>

  <Step title="Выберите тип доступа">
    Выберите тип доступа коннектора:

    - **Public** делает всё проиндексированное содержимое Canvas видимым каждому пользователю Yahont.
    - **Private** ограничивает весь коннектор выбранными пользователями и группами Yahont.
    - **Auto Sync Permissions** воспроизводит поддерживаемое управление доступом Canvas и доступна в Yahont Cloud
    и Enterprise Edition.
  </Step>

  <Step title="Подключите и проверьте">
    Нажмите **Connect**. Затем откройте **Панель администратора → Существующие коннекторы**,
    выберите коннектор и убедитесь, что первая попытка индексации завершилась.
  </Step>
</Steps>

## Автосинхронизация прав {#auto-sync-permissions}

При **Auto Sync Permissions** Yahont сопоставляет видимость в Canvas с пользователями Yahont по адресу электронной
почты. Адреса электронной почты пользователей Canvas должны совпадать с адресами пользователей в Yahont. Пользователи,
которых Canvas вернул без адреса электронной почты, доступа не получают.

Токен должен уметь читать адреса электронной почты в списках курсов.
При сохранении коннектора Canvas с синхронизацией прав Yahont проверяет список первого доступного курса и отклоняет
коннектор, если адреса электронной почты не видны.

| Элемент Canvas | Кто видит его в Yahont |
| --- | --- |
| Страницы, объявления для всего курса и задания, не ограниченные переопределениями | Все в списке курса (активные и приглашённые зачисления) |
| Объявления для конкретных разделов | Эти разделы, а также преподаватели, ассистенты и дизайнеры |
| Задания с **only visible to overrides** | Студенты, разделы и группы Canvas из переопределения, а также преподаватели, ассистенты и дизайнеры |

Курсы, которые Canvas помечает как публичные или публичные для аутентифицированных пользователей,
также дают доступ группе всех пользователей, если токен может перечислять пользователей аккаунта Canvas.
Если токен не может перечислять пользователей аккаунта, эти элементы для всего курса ограничены списком курса.
Объявления для конкретных разделов и задания только для переопределений остаются ограниченными даже в публичном курсе.

<Warning>
  Проверьте тип доступа перед подключением.
  Выбор **Public** не сохраняет права Canvas и может открыть проиндексированное содержимое каждому пользователю Yahont.
</Warning>

## Синхронизация групп {#group-sync}

При **Auto Sync Permissions** Yahont также строит группы пользователей из Canvas,
чтобы доступ сохранялся при изменении списков без повторной индексации. Создаются четыре вида групп:

| Группа Yahont         | Участники                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `canvas-course-<id>` | Все в списке курса, из активных и приглашённых зачислений.                                                              |
| `canvas-section-<id>` | Участники раздела курса.                                                                                               |
| `canvas-group-<id>`  | Участники группы Canvas.                                                                                                |
| `canvas-all-users`   | Все пользователи аккаунта Canvas. Создаётся, только если хотя бы один курс публичный и только если токен может перечислять пользователей аккаунта. |

Разделы и группы Canvas создаются только там, где на них что-то ссылается: зачисление в раздел,
объявление для раздела или переопределение задания. Группа Canvas,
на которую не ссылается ни одно переопределение задания, не синхронизируется.

Права документов и группы обновляются каждые 30 минут.
Задайте `CANVAS_PERMISSION_DOC_SYNC_FREQUENCY` и `CANVAS_PERMISSION_GROUP_SYNC_FREQUENCY` (секунды), чтобы изменить их.
Права привязываются при первичной индексации,
поэтому новый коннектор доступен для поиска нужным людям с первой попытки индексации.

## Ограничения {#limits}

| Ограничение            | Значение | Примечания                                                                  |
| ---------------------- | ------ | ----------------------------------------------------------------------------- |
| Вызов API Canvas       | 30 с   | Запрос Canvas, не ответивший вовремя, завершает попытку индексации с ошибкой. |
| Результатов на страницу API | 100 | Yahont постранично читает курсы, списки и пользователей аккаунта этим размером. |
| Синхронизация прав     | 30 мин | `CANVAS_PERMISSION_DOC_SYNC_FREQUENCY`                                       |
| Синхронизация групп    | 30 мин | `CANVAS_PERMISSION_GROUP_SYNC_FREQUENCY`                                     |

У коннектора нет ограничения размера файла, потому что он не индексирует файлы. Он читает текст страниц,
заданий и объявлений через API Canvas и не загружает вложения курсов.

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Учётные данные отклонены или токен истёк">
    Ошибка вида `Canvas API token is invalid or expired (HTTP 401)` означает, что токен отсутствует,
    отозван или просрочен. Создайте новый токен доступа в Canvas и обновите учётные данные в Yahont. Убедитесь,
    что **Canvas Base URL** — HTTPS-URL того же инстанса Canvas, который выдал токен.
  </Accordion>

  <Accordion title="У токена недостаточно прав">
    `Canvas API token does not have sufficient permissions (HTTP 403)` означает,
    что пользователь Canvas не может вызвать используемый API.
    Для индексации нужен доступ к доступным курсам пользователя и к опубликованным страницам,
    опубликованным заданиям и активным объявлениям в этих курсах.
    Для синхронизации прав дополнительно нужна видимость адресов электронной почты в списке хотя бы одного доступного
    курса.
  </Accordion>

  <Accordion title="Базовый URL Canvas отклонён">
    URL должен включать хост и использовать `https`. Введите сайт Canvas, например `https://school.instructure.com`,
    а не URL с `http`.
  </Accordion>

  <Accordion title="Курс, страница, задание или объявление отсутствует">
    Убедитесь, что пользователь Canvas токена может открыть элемент.
    Yahont перечисляет только курсы в состоянии `available`, только опубликованные страницы,
    только опубликованные задания и только активные объявления.
    Страницы и задания без `updated_at` и объявления без `posted_at` пропускаются при обновлении. Курс,
    вернувший HTTP 404, пропускается в этой попытке индексации.
  </Accordion>

  <Accordion title="Синхронизация прав не работает при создании коннектора">
    Убедитесь, что вы используете Yahont Cloud или Enterprise Edition. Переподключитесь с токеном,
    который может читать пользователей курса с адресами электронной почты.
    Токены студентов обычно не проходят эту проверку.
  </Accordion>

  <Accordion title="Пользователи не видят содержимое, которое могут открыть в Canvas">
    Убедитесь,
    что адрес электронной почты пользователя в Canvas совпадает с его адресом в Yahont и что Canvas вернул адрес
    электронной почты для этого пользователя в списке курса. Приглашённые и активные зачисления включены;
    другие состояния зачисления — нет.
    Задания только для переопределений и объявления для конкретных разделов ограничены этими целями,
    а также преподавателями, ассистентами и дизайнерами.
  </Accordion>

  <Accordion title="Публичные курсы Canvas ограничены списком курса">
    Токен не может перечислять пользователей аккаунта.
    Страницы публичных курсов и другие элементы для всего курса тогда используют только список курса.
    Используйте токен администратора Canvas, если нужно сопоставление со всеми пользователями для публичных курсов.
  </Accordion>
</AccordionGroup>
