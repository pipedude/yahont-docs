Коннектор Confluence индексирует страницы, которые видит его учётная запись коннектора.
Он также индексирует комментарии к страницам, метки, последних редакторов, иерархию и вложения,
если включена обработка вложений.
После первой полной синхронизации Yahont по умолчанию проверяет обновления каждые 30 минут.
Интервал обновления можно изменить в настройках коннектора.

## Выбор развёртывания {#choose-your-deployment}

| Развёртывание | Аутентификация | Wiki Base URL | Настройка Yahont |
| --- | --- | --- | --- |
| Confluence Cloud | OAuth Yahont Cloud или API-токен Atlassian | `https://your-domain.atlassian.net/wiki` | Включите **Is Cloud** |
| Confluence Data Center | Персональный токен доступа (PAT) | Корень вашего сайта или контекстный путь | Отключите **Is Cloud** |
| Confluence Server | Персональный токен доступа (PAT), доступен в версии 7.9 и новее | Корень вашего сайта или контекстный путь | Отключите **Is Cloud** |

- Для сайта, размещённого Atlassian, следуйте [настройке Confluence Cloud](./confluence-cloud).
- Для сайта, которым вы управляете сами, следуйте [настройке Confluence Data Center и Server](./confluence-data-center).

<Warning>
  Atlassian прекратила поддержку Confluence Server 15 февраля 2024 года.
  Yahont по-прежнему использует для Server путь интеграции Data Center,
  но Atlassian рекомендует перейти на Cloud или Data Center. См.
  [уведомление Atlassian о прекращении поддержки Server](https://www.atlassian.com/licensing/server-end-of-support).
</Warning>

## Настройка коннектора в Yahont {#configure-the-connector-in-onyx}

Сначала выполните шаги аутентификации из руководства для вашего развёртывания.
Затем откройте **Панель администратора > Коннекторы**, выберите **Confluence** и выполните следующие шаги.

<Steps>
  <Step title="Добавьте учётные данные">
    Нажмите **Создать**. Введите понятное название,
    учётную запись коннектора и токен из руководства для вашего развёртывания.

    - Cloud: введите адрес электронной почты аккаунта Atlassian и его API-токен.
    - Data Center или Server: введите имя пользователя владельца PAT и сам PAT. Yahont отправляет PAT как bearer-токен.

    ![Форма учётных данных Confluence](/assets/admins/connectors/confluence/credential-form.jpg)
  </Step>

  <Step title="Задайте развёртывание и URL">
    Введите название коннектора и настройте поля развёртывания:

    - **Is Cloud**: включайте только для Confluence Cloud.
    - **Wiki Base URL**: для Cloud включите `/wiki`. Для Data Center или Server введите корень сайта или настроенный контекстный
    путь. Не добавляйте `/rest/api`.
    - **Using scoped token**: включайте только для API-токена Confluence Cloud, созданного с областями. Оставьте
    выключенным для Cloud-токена без областей и для Data Center или Server.

    ![Настройки коннектора Confluence Cloud](/assets/admins/connectors/confluence/connector-form-cloud.jpg)
  </Step>

  <Step title="Выберите, что индексировать">
    Выберите одну область:

    | Область | Результат |
    | --- | --- |
    | **Everything** | Индексируется каждая страница, которую видит учётная запись коннектора. |
    | **Space** | Индексируется одно пространство по его ключу, например `ENG` или `KB`. |
    | **Page** | Индексируется одна страница по числовому ID страницы. Включите **Index Recursively**, чтобы включить её потомков. |
    | **CQL Query** | Индексируются страницы, возвращённые пользовательским запросом на языке Confluence Query Language. |

    Запрос CQL должен использовать `type=page` как единственный фильтр типа содержимого.
    Не добавляйте фильтр `lastmodified`.
    Yahont добавляет собственные временные фильтры при инкрементальной синхронизации.
    Фильтр в вашем запросе может с ними конфликтовать.
    Yahont по-прежнему получает комментарии и включённые вложения для возвращённых страниц. См.
    [документацию CQL](https://developer.atlassian.com/server/confluence/advanced-searching-using-cql/) от Atlassian.
  </Step>

  <Step title="Выберите обработку вложений">
    Оставьте **Include Attachments** включённым,
    чтобы извлекать поддерживаемые документы-вложения из проиндексированных страниц.
    Анализ вложений-изображений также требует настройки извлечения и анализа изображений в Yahont.
    Отключите обработку вложений, если нужны только текст страниц и комментарии.
  </Step>

  <Step title="Выберите управление доступом">
    Выберите **Advanced** и выберите тип доступа:

    - **Public** делает каждый проиндексированный документ доступным каждому пользователю Yahont.
    - **Private** ограничивает каждый проиндексированный документ назначенными коннектору группами Yahont.
    - **Sync Permissions** воспроизводит права на пространства Confluence,
    ограничения страниц и унаследованные ограничения родительских страниц.

    Синхронизация прав требует Yahont Enterprise Edition или Yahont Cloud.
    Она сопоставляет пользователей Confluence с пользователями Yahont по адресу электронной почты и синхронизирует
    группы Confluence. Прочитайте руководство для вашего развёртывания, прежде чем включать её.
  </Step>

  <Step title="Создайте и проверьте">
    Нажмите **Create Connector**. Коннектор проверяет учётные данные, читая хотя бы одно видимое пространство.

    Откройте страницу статуса коннектора и дождитесь завершения первой попытки индексации.
    Затем найдите в Yahont известную страницу. Откройте ссылку на источник результата и убедитесь,
    что она ведёт на нужную страницу Confluence.
  </Step>
</Steps>

## Поведение синхронизации прав {#permission-sync-behavior}

Yahont применяет ближайшее ограничение чтения в таком порядке:

- Ограничение страницы.
- Ближайшая родительская страница с ограничением.
- Права на пространство страницы.

Yahont сопоставляет пользователей по адресу электронной почты. Отсутствующий, скрытый,
замаскированный или другой адрес электронной почты не позволяет сопоставить идентификатор Confluence с пользователем
Yahont. Проверьте хотя бы одну страницу с каждым вариантом ограничений, который используется на вашем сайте.

## Устранение неполадок {#troubleshooting}

| Симптом | Что проверить |
| --- | --- |
| Пространства не найдены | Убедитесь, что аккаунт может открыть хотя бы одно пространство, базовый URL верный, а **Is Cloud** соответствует развёртыванию. |
| Cloud возвращает `401` | Замените просроченный или отозванный токен. Убедитесь, что **Using scoped token** соответствует типу токена. |
| Cloud возвращает `403` | Предоставьте аккаунту доступ к нужному пространству или странице. Для токена с областями добавьте необходимые области чтения. |
| Data Center или Server возвращает `401` | Убедитесь, что PAT актуален и базовый URL включает настроенный контекстный путь. |
| Страницы отсутствуют | Войдите как аккаунт коннектора и откройте отсутствующую страницу. Проверьте ограничения пространства, страницы и родительских страниц. |
| Синхронизация прав пропускает пользователей | Убедитесь, что Confluence показывает адрес электронной почты каждого пользователя и что этот адрес принадлежит пользователю Yahont. |
| Коннектор CQL перестаёт обновляться | Удалите фильтр `lastmodified`. Yahont добавляет временные фильтры при инкрементальной синхронизации. Используйте `type=page` как единственный фильтр типа содержимого. |
