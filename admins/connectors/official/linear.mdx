## Как это работает {#how-it-works}

Коннектор Linear получает все задачи Linear и связанные с ними комментарии.

Задачи обновляются каждые **10** минут.

## Настройка {#setup}

### Настройте приложение Linear и переменные окружения Yahont {#configure-your-linear-application-onyx-env-variables}

<Info>
  Это нужно только при самостоятельном размещении Yahont. Если вы используете [Yahont Cloud](https://cloud.yahont.ai),
  этот шаг можно пропустить.
</Info>

<Steps>
  <Step title="Создайте приложение Linear">
    [Создайте приложение Linear OAuth.](https://linear.app/settings/api)
    Этот шаг должен выполнить администратор рабочего пространства Linear, которое вы хотите подключить к Yahont.
    Callback-URL приложения должны включать `<your onyx host>/connector/oauth/callback/linear`. Например,
    для локального развёртывания с конфигурацией по умолчанию одна из строк должна быть
    `http://localhost:3000/connector/oauth/callback/linear`.
  </Step>

  <Step title="Задайте переменные окружения">
    Задайте следующие переменные окружения в вашем инстансе Yahont, используя Client ID и Signing Secret,
    выданные Linear для вашего нового приложения:

```bash
LINEAR_CLIENT_ID=
LINEAR_CLIENT_SECRET=
```
  </Step>

  <Step title="Перезапустите Yahont">
    Перезапустите ваш инстанс Yahont как обычно, чтобы применить изменения.
  </Step>
</Steps>

### Индексирование {#indexing}

<Steps>
  <Step title="Откройте коннектор Linear">
    В интерфейсе Yahont откройте панель администратора и выберите коннектор **Linear**
  </Step>

  <Step title="Авторизуйтесь через OAuth">
    Нажмите кнопку `Создать`, чтобы пройти процесс OAuth.
  </Step>

  <Step title="Вернитесь в Yahont">
    После авторизации приложения вы будете перенаправлены обратно в Yahont.
  </Step>

  <Step title="Выберите учётные данные и настройте">
    Выберите новые учётные данные и нажмите «Продолжить». Введите название коннектора и сведения о правах.
  </Step>

  <Step title="Создайте коннектор">
    Нажмите `Создать коннектор`, чтобы начать индексацию задач и комментариев Linear!
  </Step>
</Steps>
