---
title: "Coda"
description: "Индексирование страниц и таблиц из документов Coda"
---

Коннектор Coda индексирует страницы и таблицы каждого документа Coda, который может открыть настроенный API-токен.

Выбора документов нет. Yahont индексирует каждый документ, доступный аккаунту Coda, которому принадлежит токен.

## Как это работает {#how-it-works}

| Содержимое | Поведение |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Страницы | Один документ на страницу Coda. Yahont индексирует название страницы, её ссылку и текст страницы. |
| Таблицы | Один документ на таблицу, по одному разделу на строку. Строка индексируется как её название, за которым идут значения её ячеек. |
| Ссылки | Каждая страница, таблица и строка сохраняет свою ссылку на Coda в браузере, поэтому цитата открывает элемент в Coda. |
| Права | Недоступны. **Автосинхронизация прав** для Coda не предлагается, поэтому тип доступа может быть только **Публичный** или **Приватный**. |

При каждом обновлении коннектор заново читает документы, доступные токену, и индексирует страницы и таблицы,
изменённые после прошлого запуска. Таблица, строки которой не удаётся прочитать,
всё равно индексируется только по названию, поэтому таблица видна в поиске, даже когда её содержимое недоступно.

<Warning>
  Коннектор индексирует всё, что может открыть аккаунт токена, и тип доступа применяется ко всему сразу.
  Токен пользователя с широким доступом в Coda вместе с типом **Публичный** делает каждый документ,
  который может прочитать этот пользователь, видимым для каждого пользователя Yahont. Создавайте токен из аккаунта,
  доступ которого в Coda совпадает с тем, что вы хотите открыть в Yahont.
</Warning>

## Перед началом {#before-you-begin}

Вам понадобятся:

- Аккаунт Coda, который может открыть документы для индексации в Yahont
- API-токен Coda для этого аккаунта
- Аккаунт администратора Yahont

## Настройка Coda {#configure-coda}

<Steps>
  <Step title="Создайте API-токен">
    В Coda откройте настройки аккаунта и создайте API-токен. Сразу скопируйте его.

    Актуальные шаги смотрите в [документации Coda по аутентификации
    API](https://coda.io/developers/apis/v1#section/Authentication).
  </Step>
</Steps>

<Note>
  У токена тот же доступ в Coda, что и у аккаунта, который его создал. Yahont индексирует только документы,
  страницы и таблицы, которые может открыть этот аккаунт.
</Note>

## Настройка Yahont {#configure-onyx}

<Steps>
  <Step title="Откройте коннектор Coda">
    В Yahont перейдите в **Панель администратора → Добавить коннектор** и выберите **Coda**.
  </Step>

  <Step title="Создайте учётные данные">
    Вставьте токен в поле **Coda Bearer Token**. Yahont проверяет токен при сохранении учётных данных и отклоняет его,
    если Coda возвращает ошибку аутентификации.

    <img className="rounded-image" src="/assets/admins/connectors/coda/CodaCredential.png" alt="Создание учётных данных Coda с названием и bearer-токеном Coda"/>
  </Step>

  <Step title="Задайте название коннектора">
    Задайте коннектору понятное название. Других настроек у коннектора Coda нет: что индексировать, определяет токен.
  </Step>

  <Step title="Выберите тип доступа">
    **Публичный** делает всё проиндексированное содержимое Coda видимым для каждого пользователя Yahont.
    **Приватный** ограничивает коннектор выбранными группами пользователей Yahont. Это функция Enterprise Edition:
    группы пользователей в Yahont CE недоступны.
  </Step>

  <Step title="Подключитесь и проверьте">
    Нажмите **Создать коннектор**. Затем откройте **Панель администратора → Существующие коннекторы**,
    выберите коннектор и убедитесь, что первая попытка индексации завершилась.
  </Step>
</Steps>

## Ограничения {#limits}

| Ограничение | Значение | Примечания |
| -------------------- | ----- | ------------------------------------------------------------------------------ |
| Вызов API Coda | 30 с | Запрос к Coda, на который нет ответа вовремя, завершается ошибкой после повторов ниже. |
| Повторов на запрос | 3 | С паузой между попытками. |

Yahont сам ограничивает частоту своих вызовов API Coda. Коннектор не скачивает файлы,
поэтому ограничения на размер файла нет: он индексирует текст страниц и значения ячеек таблиц через API.

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Токен отклонён или истёк">
    `Coda credential appears to be invalid or expired (HTTP 401)` означает, что токен неверный или отозван.
    Создайте новый токен в Coda и обновите учётные данные в Yahont.
  </Accordion>

  <Accordion title="Рабочее пространство не найдено">
    `Coda workspace not found or not accessible (HTTP 404)` означает,
    что аккаунт токена не может получить доступ к рабочему пространству. Убедитесь,
    что рабочее пространство открыто для этого аккаунта.
  </Accordion>

  <Accordion title="Индексация останавливается с ошибкой лимита запросов">
    `Validation failed due to Coda rate-limits being exceeded (HTTP 429)` означает,
    что Coda ограничивает запросы аккаунта. Подождите и повторите попытку.
    Yahont уже сам ограничивает частоту и повторяет свои вызовы, поэтому постоянная ошибка 429 обычно означает,
    что токен использует что-то ещё.
  </Accordion>

  <Accordion title="Нет документа, страницы или таблицы">
    Убедитесь, что аккаунт Coda, которому принадлежит токен, может это открыть. Yahont индексирует только то,
    что доступно этому аккаунту, поэтому документ, открытый для другого аккаунта, не индексируется. Таблица,
    строки которой не удаётся прочитать, индексируется только по названию.
  </Accordion>
</AccordionGroup>
