## Как это работает {#how-it-works}

Коннектор Drupal Wiki индексирует содержимое вашего инстанса Drupal Wiki, включая пространства, страницы и, при желании,
вложения. Коннектор получает весь доступный контент при первоначальной настройке,
а затем выполняет инкрементальные обновления, чтобы ваша база знаний оставалась синхронизированной.

Коннектор учитывает права предоставленного API-токена и индексирует только тот контент, к которому у токена есть доступ,
будь он публичным или приватным.

## Настройка {#setting-up}

### Авторизация {#authorization}

Вам понадобится токен доступа API для вашего инстанса Drupal Wiki.
Токен должен начинаться с `pat:` (Personal Access Token).

<Steps>
  <Step title="Откройте ваш инстанс Drupal Wiki">
    Откройте ваш инстанс Drupal Wiki
  </Step>

  <Step title="Создайте токен доступа">
    Следуйте документации, чтобы создать токен доступа:
    [https://help.drupal-wiki.com/node/605#2-Zugriffs-Token-generieren](https://help.drupal-wiki.com/node/605#2-Zugriffs-Token-generieren)
  </Step>

  <Step title="Убедитесь, что REST API доступен">
    Убедитесь, что интерфейс REST API доступен в вашем инстансе Drupal
  </Step>

  <Step title="Скопируйте API-токен">
    Скопируйте созданный API-токен (он должен начинаться с `pat:`)
  </Step>
</Steps>

<Info>
  API-токен определяет, какое содержимое будет доступно Yahont. Будет проиндексировано только то содержимое,
  к которому у пользователя токена есть доступ.
</Info>

### Индексирование {#indexing}

<Steps>
  <Step title="Откройте панель администратора">
    Откройте панель администратора и выберите коннектор **Drupal Wiki**
  </Step>

  <Step title="Укажите конфигурацию Drupal Wiki">
    На **шаге 1** укажите конфигурацию Drupal Wiki:
    - **API Token**: созданный вами токен доступа (начинается с `pat:`)
  </Step>

  <Step title="Выберите область индексации">
    На **шаге 2** выберите область индексации:
    - **Base URL**: базовый URL вашего инстанса Drupal Wiki (например, `https://help.drupal-wiki.com`)
    - **All Content**: индексировать все пространства и страницы, доступные вашему API-токену
    - **Specific Spaces**: введите ID конкретных пространств, чтобы индексировать только определённые области
    - Чтобы найти ID пространств, обратитесь к: [https://help.drupal-wiki.com/node/606](https://help.drupal-wiki.com/node/606)
    - **Specific Pages**: введите ID конкретных страниц (узлов), чтобы индексировать только определённые страницы
  </Step>

  <Step title="Настройте дополнительные параметры">
    Настройте дополнительные параметры:
    - **Include Attachments**: отметьте, чтобы также индексировать вложенные файлы (PDF, DOC, DOCX, XLS, XLSX, PPT,
    PPTX, TXT, HTML, MD, CSV)
  </Step>

  <Step title="Подключите и запустите индексацию">
    Нажмите кнопку `Подключить`!
    Содержимое вашего Drupal Wiki будет проиндексировано и будет поддерживаться в актуальном состоянии с помощью
    инкрементальной синхронизации.
  </Step>
</Steps>

## Поддерживаемые типы содержимого {#supported-content-types}

Коннектор Drupal Wiki индексирует следующее содержимое:

- **Пространства**: организационные единицы в вашем Drupal Wiki
- **Страницы**: отдельные вики-страницы с HTML-содержимым (преобразуется в обычный текст)
- **Вложения** (необязательно): различные форматы документов размером до 10 МБ

## Технические подробности {#technical-details}

- **Использование API**: использует конечные точки REST API Drupal Wiki
- **Синхронизация**: поддерживает инкрементальные обновления для эффективной синхронизации
- **Ограничения содержимого**: 10 МБ для вложений, 600 000 символов для текстового содержимого
- **Поддержка развёртываний**: работает как с самостоятельно размещёнными, так и с облачными инстансами Drupal Wiki

## Синхронизация прав {#permission-syncing}

Коннектор автоматически учитывает систему прав вашего Drupal Wiki. Доступ к содержимому определяется правами API-токена,
поэтому в Yahont индексируется и доступно для поиска только то, на что есть разрешение.
