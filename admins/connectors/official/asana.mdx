## Как это работает {#how-it-works}

Коннектор Asana получает задачи и связанные с ними комментарии из указанных проектов или из всех проектов рабочего
пространства.

## Настройка {#setting-up}

### Авторизация {#authorization}

<Steps>
  <Step title="Создайте персональный токен доступа">
    - Войдите в свой аккаунт Asana и откройте https://app.asana.com/0/my-apps
    - Нажмите «Create New Personal Access Token»
    - Задайте ему имя (например, «Yahont Integration») и создайте токен
    - Скопируйте токен — его нужно будет передать в Yahont
  </Step>
</Steps>

### Индексирование {#indexing}

<Steps>
  <Step title="Откройте коннектор Asana">
    Откройте панель администратора и выберите коннектор **Asana**
  </Step>

  <Step title="Укажите конфигурацию">
    - **Asana API Token**: вставьте персональный токен доступа, созданный ранее
    - **Workspace ID**: введите ID вашего рабочего пространства Asana. Его можно найти по адресу https://app.asana.com/api/1.0/workspaces. Это число вида 1234567890123456.
    - **Project IDs** (необязательно): чтобы индексировать отдельные проекты, введите их ID через запятую. Оставьте поле пустым, чтобы индексировать все проекты рабочего пространства. Пример: 1234567890123456,2345678901234567. ID проекта можно найти, нажав на проект в Asana. В URL он выглядит как https://app.asana.com/0/1208338159336610/1208338159510597, где «1208338159336610» — ID проекта.
    - **Team ID** (необязательно): если нужно индексировать задачи, видимые команде, в дополнение к публичным задачам,
    введите ID команды. Оставьте пустым, если эта возможность не нужна.
  </Step>

  <Step title="Запустите индексацию">
    Нажмите «Подключить», чтобы запустить индексацию
  </Step>
</Steps>

Примечание: коннектор учитывает права пользователя, связанного с указанным API-токеном. Убедитесь,
что у этого пользователя есть доступ ко всем проектам, которые вы хотите проиндексировать.
