<Note>
  Агент по коду — **бета**-действие.
  По умолчанию оно отключено и пока поддерживает только **публичные** репозитории GitHub.
</Note>

Действие «Агент по коду» позволяет вашим агентам исследовать репозиторий GitHub и отвечать на вопросы о его кодовой
базе. Оно клонирует репозиторий в изолированную песочницу, изучает код командами оболочки и возвращает письменный ответ.

## Возможности {#capabilities}

- **Вопросы и ответы по кодовой базе**: ответы на вопросы о том, как реализован репозиторий и где находится логика
- **Исследование кода**: отслеживание потока данных и взаимодействия компонентов
- **Адаптация новичков**: краткое описание структуры проекта и ключевых модулей

## Как это работает {#how-it-works}

При вызове агент по коду:

<Steps>
  <Step title="Клонирует репозиторий">
    Целевой репозиторий GitHub клонируется в изолированную песочницу.
  </Step>

  <Step title="Исследует код">
    Итеративный цикл под управлением LLM выполняет команды оболочки, чтобы изучить кодовую базу.
  </Step>

  <Step title="Возвращает ответ">
    На основе найденного формируется итоговый ответ.
  </Step>
</Steps>

Агент по коду работает в той же изолированной среде, что и [интерпретатор кода](/admins/actions/code_interpreter),
поэтому ему нужен подключённый сервер выполнения кода (bash).

## Настройка {#configuration}

Агент по коду — встроенное действие, но поскольку оно в бете, оно **отключено по умолчанию**.

<Steps>
  <Step title="Включите действие">
    Откройте **панель администратора** и перейдите на вкладку **Действия**.
    Найдите действие **Агент по коду** и включите его.
  </Step>

  <Step title="Убедитесь, что сервер выполнения кода подключён">
    Агент по коду использует ту же изолированную среду bash, что и интерпретатор кода.
    Убедитесь в панели администратора, что сервер выполнения кода подключён и работает исправно.
  </Step>

  <Step title="Подключите его к агенту">
    Включите действие **Агент по коду** у [агентов](/admins/agents/overview), которые должны им пользоваться.
    После этого LLM сама решает, когда его вызывать.
  </Step>
</Steps>

## Использование агента по коду {#using-the-coding-agent}

Когда действие включено и подключено к агенту, LLM сама решает, когда вызывать агента по коду,
исходя из запроса пользователя, — явный вызов не нужен.

<Tip>
  Явно указывайте, какой репозиторий нужно проанализировать. Например:
  *«Используя репозиторий https://github.com/onyx-dot-app/onyx, объясни, как работает конвейер индексации коннекторов.»*
</Tip>

## Ограничения {#limitations}

- **Только публичные репозитории**: приватные репозитории пока не поддерживаются, клонирование завершится ошибкой.
  Поддержка приватных репозиториев запланирована.
- **Бета**: поведение и настройки могут меняться по мере развития функции.
