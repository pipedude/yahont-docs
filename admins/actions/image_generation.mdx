Действие «Генерация изображений» позволяет агентам создавать изображения по текстовым запросам.
После настройки любая ИИ-модель в Yahont может вызывать это действие и генерировать изображения с помощью поддерживаемых
моделей.

## Поддерживаемые модели {#supported-models}

| Модель | Поставщик |
| ----- | -------- |
| GPT Image 2.5 Flare | OpenAI, Azure OpenAI, RouterAI, Polza.AI |
| GPT Image 2.5 Sunburst | OpenAI, Azure OpenAI, RouterAI, Polza.AI |
| GPT Image 2 | OpenAI, Azure OpenAI |
| GPT Image 1.5 | OpenAI, Azure OpenAI |
| GPT Image 1 | OpenAI, Azure OpenAI |
| Gemini 2.5 Flash Image (Nano Banana) | Google Cloud Vertex AI |
| Gemini 3 Pro Image (Nano Banana Pro) | Google Cloud Vertex AI |

RouterAI и Polza.AI работают в России без VPN.

## Настройка {#configuration}

<Steps>
  <Step title="Откройте «Генерация изображений»">
    Откройте **панель администратора** и выберите **Генерация изображений**.

    <img className="rounded-image" src="/assets/admins/actions/image_generation_overview.png" alt="Страница настройки генерации изображений"/>
  </Step>

  <Step title="Подключите модель">
    На странице показаны доступные модели, сгруппированные по поставщикам.

    Нажмите **Подключить** рядом с нужной моделью. Откроется окно с полями, которые зависят от поставщика:

    <Tabs>
      <Tab title="OpenAI, RouterAI, Polza.AI">
        - **API-ключ**: введите новый ключ или выберите уже подключённого провайдера с тем же шлюзом
      </Tab>

      <Tab title="Azure OpenAI">
        - **Целевой URI**: адрес endpoint Azure OpenAI вместе с именем развёртывания и версией API (`api-version`)
        - **API-ключ**: ключ Azure OpenAI
      </Tab>

      <Tab title="Google Cloud Vertex AI">
        - **Метод аутентификации**: «JSON сервисного аккаунта» или «Workload Identity (GKE)»
        - **Файл учётных данных**: загрузите или вставьте учётные данные сервисного аккаунта Google Cloud
        - **Регион**: регион Google Cloud для ваших моделей Vertex AI
        - **ID проекта GCP**: проект, где включён Vertex AI
      </Tab>
    </Tabs>

    Последняя настроенная модель автоматически становится **текущей по умолчанию**.
  </Step>

  <Step title="Управление моделью по умолчанию">
    Модель с пометкой **Текущий по умолчанию** используется,
    когда пользователи запрашивают генерацию изображений в чате.

    - Чтобы назначить моделью по умолчанию другую подключённую модель: нажмите **Сделать по умолчанию**
    - Чтобы **снять** модель с роли модели по умолчанию: нажмите пометку «Текущий по умолчанию» на этой модели
    - Чтобы **изменить учётные данные**: нажмите значок настроек (шестерёнку), чтобы открыть окно,
    где можно обновить API-ключ
    - Чтобы **отключить** провайдера: нажмите «Отключить». Yahont удалит его учётные данные
    и предложит заменить модель по умолчанию
  </Step>
</Steps>

## Использование генерации изображений {#using-image-generation}

Когда генерация изображений настроена и выбрана модель по умолчанию,
любая ИИ-модель в Yahont может вызывать действие генерации изображений. Когда пользователь просит изображение,
агент автоматически использует настроенную модель генерации изображений по умолчанию.
