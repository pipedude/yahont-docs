## Руководство {#guide}

Настройте Yahont на использование моделей, доступных через шлюз [RouterAI](https://routerai.ru/).
RouterAI работает по протоколу OpenAI Chat Completions.

В Yahont CE вы используете собственный ключ (BYOK). Кошелька платформы нет. Как получить ключ,
цены и список моделей — смотрите на [сайте RouterAI](https://routerai.ru/).

<Steps>
  <Step title="Получите API-ключ">
    Войдите в аккаунт на [сайте RouterAI](https://routerai.ru/) и создайте API-ключ.
  </Step>

  <Step title="Откройте «Языковые модели»">
    Откройте **Панель администратора → Языковые модели**.
    В группе **Шлюзы и роутеры** найдите карточку **RouterAI** и нажмите **Подключить**.
  </Step>

  <Step title="Заполните настройки">
    - **API Base URL** (обязательно): адрес API шлюза вместе с версией. По умолчанию подставлен
    `https://routerai.ru/api/v1`. Адрес можно изменить.
    - **API-ключ** (обязательно): ключ, который вы получили в RouterAI.
    - **Отображаемое имя** (необязательно): так Yahont называет поставщика в приложении.
  </Step>

  <Step title="Загрузите список моделей">
    В блоке **Модели** нажмите кнопку обновления рядом с кнопкой **Выбрать все**.
    Yahont запросит у шлюза список моделей и покажет его. Выберите модели, которые должны быть видны пользователям,
    и при необходимости нажмите **Сделать по умолчанию**. Модель, которой нет в списке,
    можно добавить вручную кнопкой **Добавить модель**.
  </Step>

  <Step title="Сохраните поставщика">
    Нажмите **Подключить**.
  </Step>
</Steps>

## Какие модели показывает Yahont {#which-models-yahont-shows}

Yahont запрашивает список у шлюза (`/models`) и показывает только текстовые модели. Модели для изображений, видео,
звука и эмбеддингов в список не попадают.

- Идентификатор модели имеет вид `vendor/model`, например `anthropic/claude-sonnet-4.5`.
- Длину контекста, поддержку изображений на входе и поддержку рассуждений Yahont берёт из каталога шлюза.

## Голос и изображения {#voice-and-images}

Шлюз RouterAI подходит и для других функций Yahont. Они настраиваются отдельно и используют ваш ключ:

- **Голос** (распознавание и озвучивание): запросы идут на `/audio/transcriptions` и `/audio/speech`.
  Режима Realtime у шлюза нет. Подробнее — на странице [Голосовой режим](/admins/actions/voice_mode).
- **Генерация изображений**: подробнее — на странице [Генерация изображений](/admins/actions/image_generation).

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Список моделей не загружается">
    Проверьте адрес в поле **API Base URL** и API-ключ. Адрес должен включать версию API (`/api/v1`).
    Причину ошибки смотрите в логах. Выполните из каталога `deployment/docker_compose`:

    ```bash
    docker compose logs api_server
    ```
  </Accordion>
</AccordionGroup>
