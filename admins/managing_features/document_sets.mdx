## Обзор {#overview}

Наборы документов позволяют объединять логически связанные документы в один пакет.
Затем их можно использовать как фильтр при поиске, чтобы ограничить область информации, по которой ищет Yahont.

## Создание набора документов {#creating-a-document-set}

<Steps>
  <Step title="Откройте «Наборы документов»">
    В панели администратора откройте раздел **Наборы документов**.

    <img className="rounded-image" src="/assets/admins/document_sets/document_sets.png" alt="Наборы документов"/>
  </Step>

  <Step title="Создайте новый набор документов">
    Нажмите **Новый набор документов** и укажите название и описание вашей коллекции документов.

    <img className="rounded-image" src="/assets/admins/document_sets/new_document_set.png" alt="Новый набор документов"/>
  </Step>

  <Step title="Добавьте коннекторы">
    Выберите, какие коннекторы должны входить в этот набор документов.
    Можно объединить несколько источников данных в один набор.

    <img className="rounded-image" src="/assets/admins/document_sets/add_connectors.png" alt="Добавление коннекторов в набор документов"/>
  </Step>
</Steps>

## Сценарии использования {#use-cases}

- **Упорядоченные знания**: объединяйте связанное содержимое из разных источников в одну коллекцию.
- **Создание агентов**: назначайте агентам целые коллекции документов, чтобы они ссылались только на релевантные знания.
- **Управление доступом**: управляйте правами на уровне набора документов, связывая наборы с группами пользователей.
- **Фильтрация поиска**: позвольте пользователям искать в определённых коллекциях документов.
