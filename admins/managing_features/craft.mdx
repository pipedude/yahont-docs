В панели администратора есть отдельный раздел **Craft** с настройками, действующими во всём вашем рабочем пространстве.

| Настройка | Где найти |
| --- | --- |
| Доступ пользователей | **Панель администратора → Craft → Доступ** |
| Приложения и политики действий | **Панель администратора → Плагины** |
| Инструкции для всего рабочего пространства | **Панель администратора → Craft → Инструкции** |
| Модели, доступные Craft | **Панель администратора → Языковые модели** |
| Общий доступ к пользовательским навыкам и управление ими | **Craft → Навыки** |

Если вы размещаете Yahont самостоятельно, сначала настройте среду выполнения,
описанную в разделе [Развёртывание Craft](/deployment/local/craft). В руководстве по развёртыванию описаны песочницы,
прокси, рабочие процессы, сеть, хранилище, ресурсы и переменные окружения.

## Управление доступом {#control-access}

Откройте **Панель администратора → Craft → Доступ**.

| Элемент управления | Действие |
| --- | --- |
| **Включить Craft по умолчанию** | Включает или выключает Craft для пользователей, у которых нет индивидуального переопределения. |
| **Доступ для отдельных пользователей** | Создаёт для этого пользователя исключение из значения по умолчанию для рабочего пространства. |

Для ограниченного запуска отключите **Включить Craft по умолчанию**, затем включите доступ тем пользователям,
которым он нужен. Исключения для отдельных пользователей сохраняются,
даже если позже вы измените значение по умолчанию для рабочего пространства.

<Info>
  Отзыв доступа не позволяет пользователю начинать новую работу в Craft и пропускает будущие запуски его запланированных
  задач. Он не останавливает уже выполняемый шаг и не удаляет его сессии, файлы, навыки,
  приложения и запланированные задачи.
</Info>

## Добавление инструкций для рабочего пространства {#add-workspace-instructions}

Откройте **Панель администратора → Craft → Инструкции**, чтобы добавить рекомендации,
которым должен следовать каждый агент Craft в вашем рабочем пространстве.
Yahont добавляет эти инструкции к встроенным инструкциям Craft в виде раздела **Инструкции организации**.

Хорошие инструкции для рабочего пространства описывают стабильные ожидания,
которые должны действовать для всей работы Craft:

| Используйте инструкции рабочего пространства для | Держите в другом месте |
| --- | --- |
| Фирменного стиля, терминологии и правил оформления | Инструкции для одного рабочего процесса — поместите их в навык |
| Общих для организации правил обработки созданного содержимого | Учётные данные и секреты — настраивайте их через приложения |
| Стандартных требований к результату, таких как цитаты или оговорки | Сведения, которые меняются для каждого запроса — включайте их в запрос |

Например:

```md
For client-facing deliverables:

- Use the company name "Acme" rather than "Acme, Inc."
- Use concise, direct language and avoid unsupported performance claims.
- Add "Confidential" to draft materials unless the user requests otherwise.
```

Редактор принимает до 4000 символов. Выберите **Показать базовые инструкции**, чтобы увидеть встроенный промпт,
к которому добавляется ваш текст, или **Сбросить по умолчанию**, чтобы удалить инструкции рабочего пространства.

<Warning>
  Инструкции рабочего пространства дополняют встроенное поведение Craft.
  Они не могут переопределить его жёсткие правила, политики приложений,
  права пользователей и другие обязательные средства контроля.
</Warning>

Изменения применяются при запуске или восстановлении сессии Craft. Они не меняют сессию,
которая выполняется в данный момент. Используйте **Попробовать в Craft**,
чтобы проверить сохранённые инструкции в новой сессии.

## Настройка моделей {#configure-models}

Craft поддерживает поставщиков Anthropic, OpenAI и OpenRouter.

Пользователям также нужен доступ к поставщику и хотя бы одной видимой модели.
Предоставьте пользователям доступ к поставщику публично или через группу.
Белые списки агентов применяются к агентам Yahont, а не к Craft. Настройки видимости поставщиков см.
в разделе [Управление доступом к языковым моделям](/admins/advanced_configs/llm_access_controls).

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Раздел Craft не отображается в панели администратора">
    Убедитесь, что вы вошли как администратор. Раздел скрыт, если Craft недоступен в развёртывании.
    Операторам с самостоятельным размещением следует изучить [Развёртывание Craft](/deployment/local/craft).
  </Accordion>

  <Accordion title="У пользователя есть доступ, но он не может начать сессию">
    Убедитесь, что у пользователя есть доступ к поставщику Anthropic,
    OpenAI или OpenRouter хотя бы с одной видимой моделью. Поставщик, ограниченный только белым списком агентов,
    в Craft недоступен.
  </Accordion>

  <Accordion title="После смены значения по умолчанию у пользователя по-прежнему другой доступ">
    Проверьте настройку пользователя в **Панель администратора → Craft → Доступ**.
    Исключение для отдельного пользователя имеет приоритет над значением по умолчанию рабочего пространства,
    пока вы его не измените.
  </Accordion>

  <Accordion title="Каждое сообщение Craft завершается ошибкой «Payment Required»">
    Craft требует лицензию Business или Enterprise,
    поэтому в развёртываниях без неё каждое сообщение возвращает `FEATURE_NOT_AVAILABLE`.
    Более старые версии с самостоятельным размещением ещё показывали Craft в Community Edition.
    Последний патч-релиз вашей версии показывает вместо этого страницу обновления.
  </Accordion>

  <Accordion title="Сохранённые инструкции рабочего пространства не влияют на сессию">
    Запустите новую сессию, чтобы проверить сохранённые инструкции. Они не обновляют уже выполняемую сессию.
    Также убедитесь,
    что рекомендации не противоречат встроенным жёстким правилам Craft или обязательной политике приложения.
  </Accordion>
</AccordionGroup>
