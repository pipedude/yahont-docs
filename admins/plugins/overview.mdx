Плагины дают агентам Yahont доступ к внешним инструментам и сервисам в реальном времени.
С помощью плагина агент может прочитать актуальные данные или выполнить действие,
например отправить ответ в Slack или создать заявку.

Администраторы управляют всеми плагинами в **Панель администратора → Плагины** (`/admin/plugins`).
Пользователи подключают свои аккаунты и задают личные настройки по умолчанию в разделе **Плагины** главного меню
(`/app/plugins`).

## Что переехало в Yahont CE 0.2 {#where-things-moved-in-onyx-5}

Начиная с Yahont CE 0.2 MCP-серверы, действия OpenAPI и приложения Craft собраны на одной странице **Плагины**. Серверы,
инструменты, учётные данные и настройки приложений Craft остались прежними. Изменилось только место.

| Раньше | Теперь |
| --- | --- |
| **Панель администратора → Действия MCP** (`/admin/mcp-actions`) | **Панель администратора → Плагины**, тип **MCP** |
| **Панель администратора → Действия OpenAPI** (`/admin/openapi-actions`) | **Панель администратора → Плагины**, тип **OpenAPI** |
| **Панель администратора → Craft → Приложения** (`/admin/craft/apps`) | **Панель администратора → Плагины**, тип **Приложения Craft** |
| **Craft → Приложения** (`/craft/v1/apps`) | **Плагины** в боковом меню Craft (`/craft/v1/plugins`) |
| Инструменты MCP и OpenAPI в меню **Действия** чата | **Действия → Плагины** в чате и **Плагины** в главном меню (`/app/plugins`) |
| «Действия OpenAPI» и «действия MCP» | «Плагины OpenAPI» и «плагины MCP» |

Старые ссылки открывают новые страницы.

## Типы плагинов {#plugin-types}

В Yahont есть три типа плагинов. Каждый тип подключает свой вид внешних систем.

| Тип | Что подключает | Где его могут использовать агенты | Когда использовать |
| --- | --- | --- | --- |
| [MCP](/admins/plugins/mcp) | Сервер, который работает по [Model Context Protocol](https://modelcontextprotocol.io/) | Чат, свои агенты и Craft | Поставщик публикует MCP-сервер, или вы запускаете собственный. |
| [OpenAPI](/admins/plugins/openapi) | REST API, который вы описываете схемой OpenAPI | Чат и свои агенты | У вас есть внутренний или сторонний REST API и нет MCP-сервера. |
| [Приложение Craft](/admins/plugins/craft_apps) | Каталог конечных точек API одного приложения, например Slack или Gmail | Только Craft | Craft должен действовать от имени каждого пользователя в поддерживаемом приложении, с одобрениями на уровне действий. |

### Как выбрать тип плагина {#choose-a-plugin-type}

- Используйте **приложение Craft** для работы в Craft со Slack, Google Calendar, Google Drive, Gmail, Linear, GitHub,
  HubSpot, Notion или Zendesk. Приложения Craft обращаются к API поставщика от имени подключённого пользователя.
  У каждого действия своя политика одобрения.
- Используйте **MCP-сервер** для приложения, которого нет среди встроенных приложений Craft, или когда инструменты нужны
  ещё и в чате. MCP-серверы работают в чате, в своих агентах и в Craft.
- Используйте **плагин OpenAPI**, чтобы сделать существующий REST API доступным в чате и своих агентах.
  Yahont превращает каждую операцию схемы в инструмент.

<Tip>
  Один и тот же сервис можно добавить несколько раз. Например,
  добавьте приложение Craft для Slack для Craft и MCP-сервер Slack для чата.
</Tip>

### Плагины и коннекторы {#plugins-compared-to-connectors}

[Коннекторы](/admins/connectors/overview) и плагины решают разные задачи.

| | Коннекторы | Плагины |
| --- | --- | --- |
| Данные | Индексируют копию документов в поисковый индекс Yahont | Обращаются к внешнему сервису в реальном времени, в момент запроса |
| Права | Yahont применяет права, которые синхронизирует из источника, поэтому каждый пользователь находит только доступные ему документы | Внешний сервис применяет собственные права к аккаунту, который подключил плагин |
| Действия | Только чтение | Чтение и запись, если это разрешают сервис и плагин |

Когда пользователь подключает личный аккаунт, плагин читает только то, что доступно этому аккаунту. Например,
приложение Craft для Slack прочитает закрытый канал, только если подключённый пользователь состоит в этом канале.

## Добавление плагина {#add-a-plugin}

<Steps>
  <Step title="Откройте страницу «Плагины»">
    Нажмите значок профиля пользователя, выберите **Панель администратора**,
    затем выберите **Плагины** в разделе **Агенты и действия**.
  </Step>

  <Step title="Выберите тип плагина">
    Нажмите **Добавить**, затем выберите **MCP**, **OpenAPI** или **Приложения Craft**.

    <img className="rounded-image" src="/assets/admins/plugins/plugins_add_menu.png" alt="Меню «Добавить» с вариантами MCP, OpenAPI и Приложения Craft"/>
  </Step>

  <Step title="Завершите настройку">
    Следуйте руководству для нужного типа плагина: [MCP](/admins/plugins/mcp), [OpenAPI](/admins/plugins/openapi)
    или [приложения Craft](/admins/plugins/craft_apps).
  </Step>
</Steps>

Добавлять приложения Craft могут только полные администраторы.
Пользователи с правом **Управление действиями** могут добавлять и менять плагины MCP и OpenAPI.
Только полные администраторы могут менять, какие плагины включены в обычном чате рабочего пространства.

## Страница «Плагины» {#the-plugins-page}

Каждая карточка показывает название плагина, его адрес или описание, тип и значок состояния.

- Используйте фильтры **Все**, **MCP**, **OpenAPI** и **Приложения Craft** или поиск по названию.
- Нажмите на карточку, чтобы открыть настройки плагина.
- Нажмите значок корзины, чтобы удалить плагин.

Удаление плагина убирает его из рабочего пространства, из всех своих агентов и у всех пользователей.
Чтобы оставить плагин, но запретить его использование в обычном чате или в Craft,
выключите его переключатель доступности.

## Настройки плагина {#plugin-settings}

Настройки плагина открываются в окне с вкладками. Изменения остаются черновиком,
пока вы не нажмёте **Сохранить изменения**.

| Вкладка | MCP | OpenAPI | Приложение Craft |
| --- | --- | --- | --- |
| **Настройка** | Название, описание, доступ, доступность | Название, описания, схема, обычный чат | Название, доступность |
| **Аутентификация** | Способ аутентификации, свои заголовки, транспорт | Способ аутентификации | Учётные данные поставщика или шаблоны заголовков |
| **Инструменты** | Список инструментов и настройки одобрения в Craft | Список операций только для чтения | Политики одобрения действий |
| **Навыки** | — | — | Навыки, которые учат Craft пользоваться приложением |

## Доступность и личные настройки {#availability-and-personal-defaults}

Yahont хранит четыре вида настроек отдельно. По таблице найдите настройку, которая управляет нужным поведением.

| Настройка | Кто задаёт | Действие |
| --- | --- | --- |
| **Доступ** (MCP) | Администратор | Выбирает пользователей и группы, которые вообще могут пользоваться плагином. |
| **Включить в обычном чате** (MCP, OpenAPI) | Администратор | Делает плагин доступным в чатах без своего агента. |
| **Включить для Craft** (MCP, приложение Craft) | Администратор | Делает плагин доступным в сеансах и плановых задачах Craft. |
| **Подключение к своему агенту** | Создатель агента | Даёт одному [своему агенту](/admins/agents/overview) инструменты плагина. Настройки обычного чата на него не влияют. |
| **Личные настройки по умолчанию** | Каждый пользователь | Выключает доступный в рабочем пространстве плагин в обычном чате или в Craft этого пользователя. |
| **Подключение аккаунта** | Каждый пользователь | Входит под аккаунтом пользователя, если плагин использует личный OAuth или личные ключи API. |

Личная настройка может только сузить то, что разрешил администратор.
Если администратор выключил **Включить в обычном чате**, никто не сможет включить плагин в обычном чате. Свои агенты,
которые уже используют плагин, сохраняют его, а его учётные данные и настройки не меняются.

<Note>
  Выбор плагинов MCP и OpenAPI для обычного чата теперь находится на странице «Плагины».
  В разделе **Настройки чата** остались только встроенные инструменты, например «Внутренний поиск» и «Веб-поиск».
  В Terraform `onyx_custom_tool.enabled` задаёт выбор обычного чата для плагина OpenAPI.
</Note>

## Значки состояния {#status-icons}

Значок состояния на каждой карточке показывает, где доступен плагин. Наведите курсор на значок,
чтобы увидеть подробности. Каждый сегмент значка — отдельное место использования: **Основной чат**,
**Свои агенты** и **Craft**.

| Цвет | Значение |
| --- | --- |
| Зелёный | Включён и готов к работе |
| Оранжевый | Выключен или пользователю нужно войти |
| Серый | Этот тип плагина не поддерживает такое место использования |

Значок состояния доступен только для чтения. Меняйте доступность на вкладке **Настройка** плагина.

## Одобрения в Craft {#approvals-in-craft}

Craft может попросить пользователя одобрить действие перед выполнением.
Администраторы задают политику для каждого инструмента MCP и каждого действия приложения Craft:

| Политика | Действие |
| --- | --- |
| **Автоодобрение** | Действие выполняется без запроса. |
| **Спрашивать** | Craft показывает карточку одобрения. Пользователь может одобрить один раз, одобрить на сеанс или отклонить. |
| **Выключено** | Действие не выполняется никогда. Пользователи и плановые задачи не могут это изменить. |

Включите **Разрешить пользователям менять настройки одобрения**,
чтобы пользователи могли выбрать более строгую или более мягкую политику для действий,
которые администратор не выключил.

<Warning>
  Политики одобрения действуют только в Craft.
  В обычном чате и в своих агентах агент вызывает инструменты MCP и OpenAPI без запроса на одобрение.
  Выключите в чате инструменты, которые нельзя запускать без проверки.
</Warning>
