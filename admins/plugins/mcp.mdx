<Note>
  В Yahont CE 0.2 MCP-серверы переехали с отдельной страницы администратора в **Панель администратора → Плагины**. См.
  [Что переехало](/admins/plugins/overview#where-things-moved-in-onyx-5).
</Note>

Плагин MCP подключает Yahont к серверу, который работает по [Model Context Protocol](https://modelcontextprotocol.io/).
Yahont — это MCP-клиент. Он находит инструменты на сервере, а агенты вызывают эти инструменты во время разговора.

Плагины MCP работают в обычном чате, в своих агентах и в Craft. Используйте плагин MCP,
если поставщик публикует MCP-сервер,
если вы запускаете собственный сервер или если для приложения нет встроенного [приложения
Craft](/admins/plugins/craft_apps).

<Info>
  Чтобы другие MCP-клиенты могли использовать Yahont как сервер, см.
  [MCP-сервер Yahont](/overview/yahont_anywhere/mcp_server).
</Info>

## Добавление MCP-сервера {#add-an-mcp-server}

<Steps>
  <Step title="Откройте каталог MCP">
    Откройте **Панель администратора → Плагины**, нажмите **Добавить**, затем выберите **MCP**.

    <img className="rounded-image" src="/assets/admins/plugins/add_mcp_catalog.png" alt="Каталог MCP с записями Slack, HubSpot, Asana, Linear, Notion, Sentry, Atlassian и пунктом «Добавить свой MCP-сервер»"/>

    Выберите запись каталога, чтобы подставить название и адрес сервера этого поставщика. В каталоге есть Slack,
    HubSpot, Asana, Linear, Notion, Sentry и Atlassian.
    Для любого другого сервера выберите **Добавить свой MCP-сервер**.
  </Step>

  <Step title="Введите сведения о сервере">
    Введите **Название сервера** и **URL сервера MCP**.
    Yahont проверит сервер и покажет способ аутентификации и транспорт подключения, которые он обнаружил.

    <img className="rounded-image" src="/assets/admins/plugins/mcp_custom_filled.png" alt="Окно добавления MCP-сервера после того, как Yahont обнаружил отсутствие аутентификации и транспорт Streamable HTTP"/>

    У записей каталога также есть ссылка **Инструкция по настройке** на документацию поставщика.

    <img className="rounded-image" src="/assets/admins/plugins/mcp_linear_setup.png" alt="Окно добавления MCP-сервера для Linear с обнаруженным OAuth"/>

    API-сервер Yahont должен иметь доступ к этому адресу. При проверках во время настройки Yahont блокирует частные,
    loopback- и link-local-адреса.
  </Step>

  <Step title="Задайте доступность">
    На той же странице укажите, кто может пользоваться сервером и где он доступен:

    | Настройка | Действие |
    | --- | --- |
    | **Доступ** | **Для всех** открывает сервер всем пользователям. Выберите пользователей или группы, чтобы ограничить доступ. |
    | **Включить в обычном чате** | Делает инструменты доступными в чатах без своего агента. |
    | **Включить для Craft** | Делает инструменты доступными в сеансах и плановых задачах Craft. Этот переключатель показывается, только если Craft включён. |

    Нажмите **Продолжить**.
  </Step>

  <Step title="Настройте аутентификацию">
    Выберите **Способ аутентификации**. Способ, который обнаружил Yahont, помечен как **Рекомендуется**.
    О каждом способе читайте в разделе [Аутентификация](#authentication).

    <img className="rounded-image" src="/assets/admins/plugins/mcp_auth_methods.png" alt="Меню «Способ аутентификации» с вариантами OAuth, API-ключ и Без аутентификации"/>
  </Step>

  <Step title="Подключите">
    Нажмите **Подключить**. Yahont подключится к серверу, получит список его инструментов и откроет настройки сервера.
  </Step>
</Steps>

## Аутентификация {#authentication}

| Способ | Кто входит | Когда использовать |
| --- | --- | --- |
| **Без аутентификации** | Никто | Сервер публичный или защищён сетевыми средствами. |
| **API-ключ**, общий | Администратор, один раз для всех | Все пользователи могут пользоваться одной служебной учётной записью. |
| **API-ключ**, личный | Каждый пользователь | У каждого пользователя есть личный токен, и сервер должен применять права этого пользователя. |
| **OAuth** | Каждый пользователь | Сервер поддерживает OAuth. Каждый пользователь входит под своим аккаунтом. |
| **Сквозной OAuth** | Каждый пользователь, со входом в Yahont | Yahont передаёт серверу OAuth-токен пользователя, полученный при входе в Yahont. Способ показывается, только если вход в Yahont идёт через OAuth, OIDC или Google OAuth. |

При личных ключах API и OAuth каждый пользователь подключает свой аккаунт на [странице
«Плагины»](/overview/core_features/plugins). После этого MCP-сервер возвращает только те данные,
которые доступны аккаунту пользователя.

### OAuth {#oauth}

OAuth — лучший выбор для большинства серверов поставщиков, например Linear, Notion, Atlassian и Sentry.

<img className="rounded-image" src="/assets/admins/plugins/mcp_linear_oauth.png" alt="Настройки OAuth: «Настроить автоматически», «Свой OAuth-клиент» и «Использовать документ метаданных клиента»"/>

| Параметр | Действие |
| --- | --- |
| **Настроить автоматически** | Yahont регистрирует OAuth-клиент по опубликованным настройкам сервера. Используйте, если сервер поддерживает динамическую регистрацию клиентов. |
| **Свой OAuth-клиент** | Введите client ID от вашего провайдера. Добавьте client secret, только если его требует провайдер. |
| **Использовать документ метаданных клиента** | Провайдер получает документ метаданных клиента Yahont через публичный интернет. Выключите, если ваш инстанс Yahont закрытый. Тогда Yahont использует автоматическую регистрацию клиента. |

Если вы создаёте собственный OAuth-клиент, укажите для него redirect URI:

```text
https://<your-yahont-domain>/mcp/oauth/callback
```

<Warning>
  Yahont строит callback-адреса OAuth из `WEB_DOMAIN`. Укажите в `WEB_DOMAIN` адрес,
  который пользователи открывают в браузере.
</Warning>

### API-ключ {#api-key}

<img className="rounded-image" src="/assets/admins/plugins/mcp_api_key.png" alt="Настройки API-ключа: выбор личного или общего токена и поле для проверочного ключа"/>

Выберите, будет ли каждый пользователь подключаться со своим токеном или все будут использовать общий токен.
Введите ключ, чтобы проверить сервер и загрузить его инструменты. Проверочный ключ сохраняется только в вашем аккаунте.

### Дополнительные настройки {#advanced-settings}

Разверните **Дополнительные настройки**, чтобы добавить свои заголовки или сменить транспорт.

<img className="rounded-image" src="/assets/admins/plugins/mcp_advanced.png" alt="Дополнительные настройки: «Свои заголовки» и «Транспорт подключения»"/>

- **Свои заголовки** отправляются с каждым запросом. Используйте `{api_key}` для ключа API каждого пользователя и
  `{user_email}` для адреса электронной почты пользователя.
  Любой другой `{placeholder}` заставляет Yahont запросить значение у каждого пользователя при подключении.
- **Транспорт подключения** по умолчанию — **Streamable HTTP**. Выбирайте SSE, только если сервер требует
  устаревший SSE. Yahont не определяет эту настройку сам.

## Управление инструментами {#manage-tools}

Откройте сервер на странице «Плагины», затем выберите вкладку **Инструменты**.

<img className="rounded-image" src="/assets/admins/plugins/mcp_tab_tools.png" alt="Вкладка «Инструменты» со списком инструментов MCP-сервера"/>

- В разделе **Доступные инструменты** включайте и выключайте инструменты для всего рабочего пространства.
  Для массовых изменений используйте **Включить все** или **Отключить все инструменты**.
- Нажмите **Обновить инструменты**, когда сервер добавит, удалит или изменит инструменты.
- Нажмите **Сохранить изменения**, чтобы применить правки.

Когда Craft включён, вкладка **Настройки одобрения** задаёт политику Craft для каждого инструмента.

<img className="rounded-image" src="/assets/admins/plugins/mcp_tools_approval.png" alt="Настройки одобрения с вариантами «Автоодобрение», «Спрашивать» и «Выключено» для каждого инструмента"/>

| Политика | Действие в Craft |
| --- | --- |
| **Автоодобрение** | Инструмент выполняется без запроса. |
| **Спрашивать** | Craft просит пользователя одобрить каждый вызов. |
| **Выключено** | Craft никогда не запускает инструмент. |

Используйте **Разрешения**, чтобы задать политику сразу для всех инструментов.
Доступность инструментов и политики Craft — разные настройки. Инструмент,
который вы выключили в разделе **Доступные инструменты**, недоступен нигде.

<Warning>
  Политики одобрения действуют только в Craft.
  В обычном чате и в своих агентах агенты вызывают включённые инструменты MCP без запроса.
</Warning>

## Вкладка «Настройка» {#configuration-tab}

<img className="rounded-image" src="/assets/admins/plugins/mcp_after_connect.png" alt="Вкладка «Настройка» MCP-сервера"/>

| Настройка | Действие |
| --- | --- |
| **Название сервера** и **Описание** | Показываются пользователям на странице «Плагины». |
| **Доступ** | Выбирает, кто может пользоваться сервером. |
| **Включить в обычном чате** | Добавляет сервер в обычный чат рабочего пространства или убирает его. Свои агенты сохраняют свои инструменты. |
| **Включить для Craft** | Добавляет сервер в Craft или убирает его. |
| **Разрешить пользователям менять настройки одобрения** | Позволяет пользователям менять политики одобрения Craft для инструментов, которые вы не выключили. |

Если вы измените адрес сервера, Yahont удалит сохранённые подключения к этому серверу.
Пользователям придётся подключиться заново.

## Использование инструментов MCP в своих агентах {#use-mcp-tools-in-custom-agents}

Откройте редактор агента и выберите MCP-сервер в разделе **Действия**. Затем выберите инструменты,
которые сможет использовать агент. Свой агент сохраняет свои инструменты MCP,
когда вы выключаете **Включить в обычном чате**. См. [Агенты](/admins/agents/overview).
