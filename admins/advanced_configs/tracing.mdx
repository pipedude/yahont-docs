Трассировка передаёт каждый вызов LLM, который делает Yahont, на внешнюю платформу наблюдаемости,
чтобы вы могли следить за задержкой, расходом токенов и стоимостью, а также оценивать качество ответов.
Yahont поддерживает [Braintrust](https://www.braintrust.dev) и [Langfuse](https://langfuse.com).

<Note>
  Трассировка доступна в развёртываниях с **самостоятельным размещением**. В Yahont Cloud её настроить нельзя.
</Note>

## Подключение поставщика {#connect-a-provider}

<Steps>
  <Step title="Откройте панель трассировки">
    Нажмите значок профиля пользователя,
    выберите **Панель администратора** и откройте вкладку **Трассировка** в разделе **Использование** боковой панели.
  </Step>

  <Step title="Подключите Braintrust и (или) Langfuse">
    Можно подключить одного или обоих поставщиков — трассировки отправляются каждому подключённому поставщику.

    <Tabs tabs={["Braintrust", "Langfuse"]}>
      <Tab title="Braintrust">
        Создайте API-ключ на [панели Braintrust](https://www.braintrust.dev/app) в разделе **Settings → API Keys**.

        В Yahont нажмите **Подключить** на карточке Braintrust и заполните:

        - **API-ключ** — ваш API-ключ Braintrust.
        - **Название проекта** *(необязательно)* — проект Braintrust, в который записываются трассировки. По умолчанию
        `Yahont`.
        - **URL API** *(необязательно)* — нужен только для Braintrust с самостоятельным размещением или нестандартных
        регионов. По умолчанию `https://api.braintrust.dev`.
      </Tab>

      <Tab title="Langfuse">
        Создайте пару ключей в настройках проекта [Langfuse](https://cloud.langfuse.com) в разделе **Setup → API Keys**.

        В Yahont нажмите **Подключить** на карточке Langfuse и заполните:

        - **Секретный ключ** — ваш секретный ключ Langfuse (`sk-...`).
        - **Публичный ключ** — ваш публичный ключ Langfuse (`pk-...`).
        - **Базовый URL API** *(необязательно)* — по умолчанию используется регион ЕС
        (`https://cloud.langfuse.com`). Задайте его для региона США,
        другого региона или инстанса Langfuse с самостоятельным размещением.
      </Tab>
    </Tabs>

    Yahont проверяет учётные данные перед сохранением. После подключения на карточке отображается **Подключено**,
    и трассировки начинают поступать примерно через 30 секунд — перезапуск не нужен.
  </Step>
</Steps>

## Отключение поставщика {#disconnect-a-provider}

Откройте карточку поставщика, нажмите кнопку отключения и подтвердите.
Yahont сразу перестаёт отправлять новые трассировки этому поставщику. Уже доставленные трассировки не затрагиваются.

## Настройка через переменные окружения {#configuring-with-environment-variables}

Настраивать трассировку рекомендуется в панели администратора,
но Yahont также учитывает переменные окружения для обратной совместимости. Поставщик, настроенный через интерфейс,
имеет приоритет над своими переменными окружения.

| Поставщик | Переменная | Описание |
| --- | --- | --- |
| Braintrust | `BRAINTRUST_API_KEY` | API-ключ. При наличии включает трассировку Braintrust. |
| Braintrust | `BRAINTRUST_PROJECT` | Название проекта, в который записываются трассировки. По умолчанию `Onyx`. |
| Braintrust | `BRAINTRUST_API_URL` | Пользовательский URL API для самостоятельного размещения и нестандартных регионов. |
| Langfuse | `LANGFUSE_SECRET_KEY` | Секретный ключ. Обязателен (вместе с публичным ключом) для включения Langfuse. |
| Langfuse | `LANGFUSE_PUBLIC_KEY` | Публичный ключ. Обязателен (вместе с секретным ключом) для включения Langfuse. |
| Langfuse | `LANGFUSE_HOST` | Базовый URL для нестандартного региона или Langfuse с самостоятельным размещением. |

<Note>
  Поставщики, настроенные через переменные окружения,
  отображаются на панели трассировки как настроенные через окружение. Их можно перевести в конфигурацию,
  управляемую через интерфейс, подключив поставщика в панели администратора.
</Note>
